# GM1300: Element must begin with an upper-case letter

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM1300  |
| **Category** | Naming  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | No      |

## Description

The name of a C# element does not begin with an upper-case letter. The following types of elements must begin with an upper-case letter: namespaces, classes, enums, structs, delegates, events, methods, and properties.

Ported from [SA1300](https://github.com/DotNetAnalyzers/StyleCopAnalyzers/blob/master/documentation/SA1300.md).

## Violation

```csharp
class myClass { }           // GM1300 reported on 'myClass'

enum color { Red, Green }   // GM1300 reported on 'color'

class Foo
{
    void myMethod() { }     // GM1300 reported on 'myMethod'

    int myProperty { get; } // GM1300 reported on 'myProperty'
}
```

## Fix

Rename the element so its name begins with an upper-case letter.

```csharp
class MyClass { }

enum Color { Red, Green }

class Foo
{
    void MyMethod() { }

    int MyProperty { get; }
}
```

## Exceptions

- Overridden members are not checked (the name is inherited from the base type).
- Members that implement an interface are not checked.
- Enum members with an underscore followed by a digit prefix (e.g. `_1Value`) are allowed.
