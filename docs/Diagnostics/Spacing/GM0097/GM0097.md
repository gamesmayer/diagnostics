# GM0097: Space before dot

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0097  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before a dot. Equivalent to the `csharp_space_before_dot` EditorConfig option.

Applies to member access expressions and qualified names. Dots preceded by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
"hello" .Length;
System .Collections.Generic;
```

When `enabled = true`:

```csharp
"hello".Length;
System.Collections.Generic;
```

## Fix

When `enabled = false` (default):

```csharp
"hello".Length;
System.Collections.Generic;
```

When `enabled = true`:

```csharp
"hello" .Length;
System .Collections.Generic;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0097.enabled = false  # disallow space before dot (default)
dotnet_diagnostic.GM0097.enabled = true   # require space before dot
```
