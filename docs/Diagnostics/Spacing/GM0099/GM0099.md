# GM0099: Space after semicolon in for statement

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0099  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after each semicolon in a for statement. Equivalent to the `csharp_space_after_semicolon_in_for_statement` EditorConfig option.

## Violation

When `enabled = true` (default):

```csharp
for (int i = 0;i < 10;i++)
```

When `enabled = false`:

```csharp
for (int i = 0; i < 10; i++)
```

## Fix

When `enabled = true` (default):

```csharp
for (int i = 0; i < 10; i++)
```

When `enabled = false`:

```csharp
for (int i = 0;i < 10;i++)
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0099.enabled = true   # require space after semicolon in for statement (default)
dotnet_diagnostic.GM0099.enabled = false  # disallow space after semicolon in for statement
```
