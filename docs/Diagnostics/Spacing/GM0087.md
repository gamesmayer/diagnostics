# GM0087: Space after colon in inheritance clause

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0087  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after `:` in inheritance clauses. Equivalent to the `csharp_space_after_colon_in_inheritance_clause` EditorConfig option.

## Violation

When `enabled = true` (default):

```csharp
class C :I
{
}
```

When `enabled = false`:

```csharp
class C : I
{
}
```

## Fix

When `enabled = true`:

```csharp
class C : I
{
}
```

When `enabled = false`:

```csharp
class C :I
{
}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0087.enabled = true   # require a space after ':' in inheritance clause (default)
dotnet_diagnostic.GM0087.enabled = false  # disallow a space after ':' in inheritance clause
```
