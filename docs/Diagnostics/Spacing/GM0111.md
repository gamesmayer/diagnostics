# GM0111: Statement closing semicolon adjacency

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0111  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The statement-closing symbol `;` must be written immediately after the last token of the statement, with no spaces or line breaks.

## Violation

```csharp
int x = 0 ;

int y = 1
;
```

## Fix

```csharp
int x = 0;
int y = 1;
```
