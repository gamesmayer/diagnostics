# GM0111: Statement and member closing semicolon adjacency

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0111  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The statement-closing symbol `;` and class member declaration semicolons must be written immediately after the previous token, with no spaces or line breaks.

## Violation

```csharp
int x = 0 ;

int y = 1
;

private int value ;
```

## Fix

```csharp
int x = 0;
int y = 1;
private int value;
```
