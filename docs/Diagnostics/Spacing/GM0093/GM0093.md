# GM0093: Space between method call name and opening parenthesis

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0093  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between the method call name and the opening parenthesis. Equivalent to the `csharp_space_between_method_call_name_and_opening_parenthesis` EditorConfig option.

Applies to invocation expressions and object creation expressions with argument lists.

## Violation

When `enabled = true`:

```csharp
M(value);
M();
var foo = new Foo();
```

When `enabled = false` (default):

```csharp
M (value);
M ();
var foo = new Foo ();
```

## Fix

When `enabled = true`:

```csharp
M (value);
M ();
var foo = new Foo ();
```

When `enabled = false` (default):

```csharp
M(value);
M();
var foo = new Foo();
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0093.enabled = false  # disallow space between call name and opening parenthesis (default)
dotnet_diagnostic.GM0093.enabled = true   # require space between call name and opening parenthesis
```
