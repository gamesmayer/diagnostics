# GM0109: Space before assignment operator '='

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0109  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before assignment operator `=`.

Applies to assignment expressions and initializer assignments.

## Violation

When `enabled = true` (default):

```csharp
var x= 1;
int value= 0;
```

When `enabled = false`:

```csharp
var x =1;
int value =0;
```

## Fix

When `enabled = true` (default):

```csharp
var x = 1;
int value = 0;
```

When `enabled = false`:

```csharp
var x=1;
int value=0;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0109.enabled = true   # require space before assignment operator '=' (default)
dotnet_diagnostic.GM0109.enabled = false  # disallow space before assignment operator '='
```
