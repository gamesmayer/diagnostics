# GM0095: Space before comma

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0095  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before a comma. Equivalent to the `csharp_space_before_comma` EditorConfig option.

Applies to all comma-separated lists: argument lists, parameter lists, type argument lists, initializers, for-loop incrementors, and more. Commas preceded by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
void M(int a , int b) { }
M(1 , 2);
Dictionary<int , string> d;
```

When `enabled = true`:

```csharp
void M(int a, int b) { }
M(1, 2);
Dictionary<int, string> d;
```

## Fix

When `enabled = false` (default):

```csharp
void M(int a, int b) { }
M(1, 2);
Dictionary<int, string> d;
```

When `enabled = true`:

```csharp
void M(int a , int b) { }
M(1 , 2);
Dictionary<int , string> d;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0095.enabled = false  # disallow space before comma (default)
dotnet_diagnostic.GM0095.enabled = true   # require space before comma
```
