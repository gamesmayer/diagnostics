# GM0101: Space between empty square brackets

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0101  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between empty square brackets. Equivalent to the `csharp_space_between_empty_square_brackets` EditorConfig option.

Applies to empty bracket pairs in array type declarations and array creation expressions.

## Violation

When `enabled = false` (default):

```csharp
int[ ] arr;
new int[ ]{ 1, 2, 3 };
```

When `enabled = true`:

```csharp
int[] arr;
new int[]{ 1, 2, 3 };
```

## Fix

When `enabled = false` (default):

```csharp
int[] arr;
new int[]{ 1, 2, 3 };
```

When `enabled = true`:

```csharp
int[ ] arr;
new int[ ]{ 1, 2, 3 };
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0101.enabled = false  # disallow space between empty square brackets (default)
dotnet_diagnostic.GM0101.enabled = true   # require space between empty square brackets
```
