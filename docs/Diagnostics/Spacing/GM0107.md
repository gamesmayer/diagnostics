# GM0107: Space after => symbol

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0107  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after the `=>` symbol.

Applies to all `=>` arrow usages (for example, lambda expressions and expression-bodied members). Arrows followed by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
int M() => 1;
x => y;
```

When `enabled = true`:

```csharp
int M() =>1;
x =>y;
```

## Fix

When `enabled = false` (default):

```csharp
int M() =>1;
x =>y;
```

When `enabled = true`:

```csharp
int M() => 1;
x => y;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0107.enabled = false  # disallow space after => symbol (default)
dotnet_diagnostic.GM0107.enabled = true   # require space after => symbol
```
