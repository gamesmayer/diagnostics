# GM0096: Space after dot

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0096  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after a dot. Equivalent to the `csharp_space_after_dot` EditorConfig option.

Applies to member access expressions and qualified names. Dots followed by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
"hello". Length;
System. Collections.Generic;
```

When `enabled = true`:

```csharp
"hello".Length;
System.Collections.Generic;
```

## Fix

When `enabled = false` (default):

```csharp
"hello".Length;
System.Collections.Generic;
```

When `enabled = true`:

```csharp
"hello". Length;
System. Collections.Generic;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0096.enabled = false  # disallow space after dot (default)
dotnet_diagnostic.GM0096.enabled = true   # require space after dot
```
