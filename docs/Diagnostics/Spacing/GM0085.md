# GM0085: Spaces inside method call argument list parentheses

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0085  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required between method call argument list parentheses and arguments. Equivalent to the `csharp_space_between_method_call_parameter_list_parentheses` EditorConfig option.

## Violation

When `enabled = false` (default):

```csharp
var result = Compute( value );
```

When `enabled = true`:

```csharp
var result = Compute(value);
```

## Fix

When `enabled = false`:

```csharp
var result = Compute(value);
```

When `enabled = true`:

```csharp
var result = Compute( value );
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0085.enabled = false  # no spaces inside method call argument parentheses (default)
dotnet_diagnostic.GM0085.enabled = true   # require spaces inside method call argument parentheses
```
