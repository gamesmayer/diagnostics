# GM0091: Space between method declaration name and open parenthesis

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0091  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between the method name and the opening parenthesis in method declarations. Equivalent to the `csharp_space_between_method_declaration_name_and_open_parenthesis` EditorConfig option.

Applies to: method declarations, constructor declarations, destructor declarations, and local function statements.

## Violation

When `enabled = true`:

```csharp
void M(int value) { }
public Foo() { }
~Foo() { }
```

When `enabled = false` (default):

```csharp
void M (int value) { }
public Foo () { }
~Foo () { }
```

## Fix

When `enabled = true`:

```csharp
void M (int value) { }
public Foo () { }
~Foo () { }
```

When `enabled = false` (default):

```csharp
void M(int value) { }
public Foo() { }
~Foo() { }
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0091.enabled = false  # disallow space between name and open parenthesis (default)
dotnet_diagnostic.GM0091.enabled = true   # require space between name and open parenthesis
```
