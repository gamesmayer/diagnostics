# GM0094: Space after comma

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0094  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after a comma. Equivalent to the `csharp_space_after_comma` EditorConfig option.

Applies to all comma-separated lists: argument lists, parameter lists, type argument lists, initializers, for-loop incrementors, and more. Commas followed by a newline are ignored.

## Violation

When `enabled = true` (default):

```csharp
void M(int a,int b) { }
M(1,2);
Dictionary<int,string> d;
```

When `enabled = false`:

```csharp
void M(int a, int b) { }
M(1, 2);
Dictionary<int, string> d;
```

## Fix

When `enabled = true` (default):

```csharp
void M(int a, int b) { }
M(1, 2);
Dictionary<int, string> d;
```

When `enabled = false`:

```csharp
void M(int a,int b) { }
M(1,2);
Dictionary<int,string> d;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0094.enabled = true   # require space after comma (default)
dotnet_diagnostic.GM0094.enabled = false  # disallow space after comma
```
