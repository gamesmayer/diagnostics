# GM0104: Space between generic operators '<' and '>'

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0104  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required immediately inside generic angle brackets in type parameter and type argument lists.

## Violation

When `enabled = false` (default):

```csharp
class Foo< T > { }
System.Collections.Generic.List< int > values;
```

When `enabled = true`:

```csharp
class Foo<T> { }
System.Collections.Generic.List<int> values;
```

## Fix

When `enabled = false` (default):

```csharp
class Foo<T> { }
System.Collections.Generic.List<int> values;
```

When `enabled = true`:

```csharp
class Foo< T > { }
System.Collections.Generic.List< int > values;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0104.enabled = false  # disallow spaces inside generic angle brackets (default)
dotnet_diagnostic.GM0104.enabled = true   # require spaces inside generic angle brackets
```
