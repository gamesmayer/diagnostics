# GM0098: Space before open square bracket

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0098  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before an open square bracket. Equivalent to the `csharp_space_before_open_square_brackets` EditorConfig option.

Applies to element access expressions and array type declarations. Open square brackets preceded by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
arr [0];
int [] arr;
```

When `enabled = true`:

```csharp
arr[0];
int[] arr;
```

## Fix

When `enabled = false` (default):

```csharp
arr[0];
int[] arr;
```

When `enabled = true`:

```csharp
arr [0];
int [] arr;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0098.enabled = false  # disallow space before open square bracket (default)
dotnet_diagnostic.GM0098.enabled = true   # require space before open square bracket
```
