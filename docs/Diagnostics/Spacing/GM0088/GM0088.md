# GM0088: Space around binary operators

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0088  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required around binary operators. Equivalent to the `csharp_space_around_binary_operators` EditorConfig option.

## Violation

When `enabled = true` (default):

```csharp
var sum = a+b;
```

When `enabled = false`:

```csharp
var sum = a + b;
```

## Fix

When `enabled = true`:

```csharp
var sum = a + b;
```

When `enabled = false`:

```csharp
var sum = a+b;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0088.enabled = true   # require spaces around binary operators (default)
dotnet_diagnostic.GM0088.enabled = false  # disallow spaces around binary operators
```
