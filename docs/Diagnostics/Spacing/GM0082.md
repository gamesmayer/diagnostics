# GM0082: Cast expression spacing

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0082  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after a cast expression. Equivalent to the `csharp_space_after_cast` EditorConfig option.

## Violation

When set to `true` (space required):

```csharp
var x = (int)1.0f;  // GM0082 — missing space after cast
```

When set to `false` (no space, default):

```csharp
var x = (int) 1.0f;  // GM0082 — unexpected space after cast
```

## Fix

When set to `true`:

```csharp
var x = (int) 1.0f;
```

When set to `false`:

```csharp
var x = (int)1.0f;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0082.enabled = true   # space required after cast: (int) value
dotnet_diagnostic.GM0082.enabled = false  # no space after cast: (int)value (default)
```
