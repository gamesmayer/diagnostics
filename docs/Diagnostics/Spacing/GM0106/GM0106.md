# GM0106: Space before => symbol

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0106  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before the `=>` symbol.

Applies to all `=>` arrow usages (for example, lambda expressions and expression-bodied members). Arrows preceded by a newline are ignored.

## Violation

When `enabled = false` (default):

```csharp
int M() => 1;
x => y;
```

When `enabled = true`:

```csharp
int M()=> 1;
x=> y;
```

## Fix

When `enabled = false` (default):

```csharp
int M()=> 1;
x=> y;
```

When `enabled = true`:

```csharp
int M() => 1;
x => y;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0106.enabled = false  # disallow space before => symbol (default)
dotnet_diagnostic.GM0106.enabled = true   # require space before => symbol
```
