# GM0092: Space in empty method call argument list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0092  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between parentheses of an empty method call argument list. Equivalent to the `csharp_space_between_method_call_empty_parameter_list_parentheses` EditorConfig option.

Applies to invocation expressions and object creation expressions with no arguments.

## Violation

When `enabled = true`:

```csharp
M();
var f = new Foo();
```

When `enabled = false` (default):

```csharp
M( );
var f = new Foo( );
```

## Fix

When `enabled = true`:

```csharp
M( );
var f = new Foo( );
```

When `enabled = false` (default):

```csharp
M();
var f = new Foo();
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0092.enabled = false  # disallow space in empty argument list (default)
dotnet_diagnostic.GM0092.enabled = true   # require space in empty argument list
```
