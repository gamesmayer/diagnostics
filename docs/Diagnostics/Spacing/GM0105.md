# GM0105: Space around ternary operators '?' and ':'

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0105  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required around ternary operators '?' and ':' in conditional expressions.

## Violation

When `enabled = true` (default):

```csharp
var value = condition ? whenTrue : whenFalse;
```

When `enabled = false`:

```csharp
var value = condition?whenTrue:whenFalse;
```

## Fix

When `enabled = true` (default):

```csharp
var value = condition?whenTrue:whenFalse;
```

When `enabled = false`:

```csharp
var value = condition ? whenTrue : whenFalse;
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0105.enabled = true   # require spaces around '?' and ':' (default)
dotnet_diagnostic.GM0105.enabled = false  # disallow spaces around '?' and ':'
```
