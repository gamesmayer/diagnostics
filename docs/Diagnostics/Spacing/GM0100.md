# GM0100: Space before semicolon in for statement

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0100  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before each semicolon in a for statement. Equivalent to the `csharp_space_before_semicolon_in_for_statement` EditorConfig option.

## Violation

When `enabled = false` (default):

```csharp
for (int i = 0 ; i < 10 ; i++)
```

When `enabled = true`:

```csharp
for (int i = 0; i < 10; i++)
```

## Fix

When `enabled = false` (default):

```csharp
for (int i = 0; i < 10; i++)
```

When `enabled = true`:

```csharp
for (int i = 0 ; i < 10 ; i++)
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0100.enabled = false  # disallow space before semicolon in for statement (default)
dotnet_diagnostic.GM0100.enabled = true   # require space before semicolon in for statement
```
