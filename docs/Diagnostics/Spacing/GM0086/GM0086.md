# GM0086: Space before colon in inheritance clause

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0086  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before `:` in inheritance clauses. Equivalent to the `csharp_space_before_colon_in_inheritance_clause` EditorConfig option.

## Violation

When `enabled = true` (default):

```csharp
class C:I
{
}
```

When `enabled = false`:

```csharp
class C : I
{
}
```

## Fix

When `enabled = true`:

```csharp
class C :I
{
}
```

When `enabled = false`:

```csharp
class C: I
{
}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0086.enabled = true   # require a space before ':' in inheritance clause (default)
dotnet_diagnostic.GM0086.enabled = false  # disallow a space before ':' in inheritance clause
```
