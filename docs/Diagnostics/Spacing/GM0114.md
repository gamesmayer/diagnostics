# GM0114: Space between accessors in single-line property

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0114  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between adjacent accessors in a single-line property accessor list.

## Violation

When `enabled = true` (default):

```csharp
public int Value { get;set; }
public int Value { get;init; }
```

When `enabled = false`:

```csharp
public int Value { get; set; }
public int Value { get; init; }
```

## Fix

When `enabled = true` (default):

```csharp
public int Value { get; set; }
public int Value { get; init; }
```

When `enabled = false`:

```csharp
public int Value { get;set; }
public int Value { get;init; }
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0114.enabled = true   # require space between accessors in single-line properties (default)
dotnet_diagnostic.GM0114.enabled = false  # disallow space between accessors in single-line properties
```
