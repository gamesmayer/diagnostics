# GM0102: Space between square brackets

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0102  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required inside non-empty square brackets. Equivalent to the `csharp_space_between_square_brackets` EditorConfig option.

Applies to element access expressions. Cases where the content spans multiple lines are ignored.

## Violation

When `enabled = false` (default):

```csharp
arr[ 0 ];
dict[ "key" ];
```

When `enabled = true`:

```csharp
arr[0];
dict["key"];
```

## Fix

When `enabled = false` (default):

```csharp
arr[0];
dict["key"];
```

When `enabled = true`:

```csharp
arr[ 0 ];
dict[ "key" ];
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0102.enabled = false  # disallow spaces between square brackets (default)
dotnet_diagnostic.GM0102.enabled = true   # require spaces between square brackets
```
