# GM0090: Space in empty method declaration parameter list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0090  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between parentheses of an empty method declaration parameter list. Equivalent to the `csharp_space_between_method_declaration_empty_parameter_list_parentheses` EditorConfig option.

Applies to: method declarations, constructor declarations, and destructor declarations with empty parameter lists.

## Violation

When `enabled = true`:

```csharp
void M() { }
public Foo() { }
~Foo() { }
```

When `enabled = false` (default):

```csharp
void M( ) { }
public Foo( ) { }
~Foo( ) { }
```

## Fix

When `enabled = true`:

```csharp
void M( ) { }
public Foo( ) { }
~Foo( ) { }
```

When `enabled = false` (default):

```csharp
void M() { }
public Foo() { }
~Foo() { }
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0090.enabled = false  # disallow space in empty parameter list (default)
dotnet_diagnostic.GM0090.enabled = true   # require space in empty parameter list
```
