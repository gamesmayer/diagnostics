# GM0125: Space before open brace

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0125  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required before an opening brace `{` when it appears on the same line as its declaration. Applies to method bodies, property accessor lists, and other block constructs.

## Violation

When set to `true` (space required, default):

```csharp
public bool IsBusy{get; private set; }  // GM0125 — missing space before {
public void BeginRun(){ }               // GM0125 — missing space before {
```

When set to `false` (no space):

```csharp
public bool IsBusy { get; private set; }  // GM0125 — unexpected space before {
public void BeginRun() { }                // GM0125 — unexpected space before {
```

## Fix

When set to `true`:

```csharp
public bool IsBusy { get; private set; }
public void BeginRun() { }
```

When set to `false`:

```csharp
public bool IsBusy{get; private set; }
public void BeginRun(){ }
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0125.enabled = true   # space required before {: M() { (default)
dotnet_diagnostic.GM0125.enabled = false  # no space before {: M(){
```
