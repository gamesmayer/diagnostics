# GM0083: Space after control-flow keywords

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0083  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required after control-flow keywords before the opening parenthesis. Equivalent to the `csharp_space_after_keywords_in_control_flow_statements` EditorConfig option.

## Violation

When `enabled = true` (default):

```csharp
if(value)
{
}
```

When `enabled = false`:

```csharp
if (value)
{
}
```

## Fix

When `enabled = true`:

```csharp
if (value)
{
}
```

When `enabled = false`:

```csharp
if(value)
{
}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0083.enabled = true   # space required after keywords (default)
dotnet_diagnostic.GM0083.enabled = false  # no space after keywords
```
