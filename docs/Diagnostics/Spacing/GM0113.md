# GM0113: Space between single-line block braces

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0113  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required after `{` and before `}` in non-empty single-line blocks and accessor lists.

## Violation

When `enabled = true` (default):

```csharp
public IListenOnly<AdsInitializedEvent> AdsInitialized {get;}
if (isReady) {return;}
```

When `enabled = false`:

```csharp
public IListenOnly<AdsInitializedEvent> AdsInitialized { get; }
if (isReady) { return; }
```

## Fix

When `enabled = true` (default):

```csharp
public IListenOnly<AdsInitializedEvent> AdsInitialized { get; }
if (isReady) { return; }
```

When `enabled = false`:

```csharp
public IListenOnly<AdsInitializedEvent> AdsInitialized {get;}
if (isReady) {return;}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0113.enabled = true   # require spaces inside non-empty single-line block braces (default)
dotnet_diagnostic.GM0113.enabled = false  # disallow spaces inside non-empty single-line block braces
```
