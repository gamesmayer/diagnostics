# GM0108: Space after type in declarations

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0108  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether a space is required between declaration types and identifiers.

Applies to class members, variable declarations, parameter declarations, and tuple element declarations.

## Violation

When `enabled = true` (default):

```csharp
List<(string key, object value)>parameters = new();
void M(List<int>value) { }
(List<int>first, int second) pair = (new(), 2);
```

When `enabled = false`:

```csharp
List<(string key, object value)> parameters = new();
void M(List<int> value) { }
(List<int> first, int second) pair = (new(), 2);
```

## Fix

When `enabled = true` (default):

```csharp
List<(string key, object value)> parameters = new();
void M(List<int> value) { }
(List<int> first, int second) pair = (new(), 2);
```

When `enabled = false`:

```csharp
List<(string key, object value)>parameters = new();
void M(List<int>value) { }
(List<int>first, int second) pair = (new(), 2);
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0108.enabled = true   # require space between declaration type and identifier (default)
dotnet_diagnostic.GM0108.enabled = false  # disallow space between declaration type and identifier
```
