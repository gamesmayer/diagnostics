# GM0084: Spaces inside method declaration parameter list parentheses

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0084  |
| **Category** | Spacing |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether spaces are required between method declaration parameter list parentheses and parameters. Equivalent to the `csharp_space_between_method_declaration_parameter_list_parentheses` EditorConfig option.

## Violation

When `enabled = false` (default):

```csharp
void M( int value )
{
}
```

When `enabled = true`:

```csharp
void M(int value)
{
}
```

## Fix

When `enabled = false`:

```csharp
void M(int value)
{
}
```

When `enabled = true`:

```csharp
void M( int value )
{
}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0084.enabled = false  # no spaces inside method declaration parameter parentheses (default)
dotnet_diagnostic.GM0084.enabled = true   # require spaces inside method declaration parameter parentheses
```
