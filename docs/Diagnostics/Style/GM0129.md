# GM0129: Explicit object creation

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0129  |
| **Category** | Style   |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Controls whether object creation must be explicit (`new Type(...)`) or implicit (`new(...)`) when simplification is possible.

## Violation

When set to `true` (explicit required, default):

```csharp
class Item { }

class C
{
    Item field = new();            // GM0129
    void M() => field = new();     // GM0129
}
```

When set to `false` (simplify whenever possible):

```csharp
using System.Collections.Generic;

class Item { }

class C
{
    Item field = new Item();       // GM0129

    void M()
    {
        field = new Item();        // GM0129

        var list = new List<Item>();
        list.Add(new Item());      // GM0129
    }
}
```

## Fix

When set to `true`:

```csharp
class Item { }

class C
{
    Item field = new Item();
    void M() => field = new Item();
}
```

When set to `false`:

```csharp
using System.Collections.Generic;

class Item { }

class C
{
    Item field = new();

    void M()
    {
        field = new();

        var list = new List<Item>();
        list.Add(new());
    }
}
```

## Settings

Configure via `.editorconfig`:

```ini
dotnet_diagnostic.GM0129.enabled = true   # enforce explicit object creation (default)
dotnet_diagnostic.GM0129.enabled = false  # simplify to implicit object creation when possible
```
