# GM0140: Unused using directive

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0140  |
| **Category** | Style   |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Using directives that are not referenced by any code in the file should be removed.

The diagnostic is shown as faded/grayed text in the editor (using the `Unnecessary` tag), matching the appearance of IDE0005.

## Violation

```csharp
using System.Text;
class C { }
```

## Fix

```csharp
class C { }
```

## Notes

- One diagnostic is reported per unused using directive, spanning the entire directive.
- The rule uses the `Unnecessary` diagnostic tag so IDEs render unused usings as grayed-out text.
- Alias usings (`using Alias = Type;`) and static usings (`using static Type;`) are also checked.
