# GM0142: Generic array creation is not allowed

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0142  |
| **Category** | Style   |
| **Severity** | Error   |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Use `new T[0]` instead of `Array.Empty<T>()` to create empty arrays.

## Violation

```csharp
class C
{
    TaskSettings[] M()
    {
        return Array.Empty<TaskSettings>();   // GM0142 — generic array creation is not allowed
    }
}
```

## Fix

```csharp
class C
{
    TaskSettings[] M()
    {
        return new TaskSettings[0];
    }
}
```

## Notes

- `Array.Empty<T>()` is a generic helper that returns a shared empty array instance, but its use is not allowed in this codebase.
- Use `new T[0]` to explicitly create an empty array of the desired type.
