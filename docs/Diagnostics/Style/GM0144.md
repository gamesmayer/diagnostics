# GM0144: Use null-conditional operator

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0144  |
| **Category** | Style   |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Simplify null checks by using the null-conditional operator `?.` instead of an explicit ternary null check.

## Violation

```csharp
class C
{
    string M(Foo x)
    {
        return x != null ? x.Value : null;   // GM0144 — use null-conditional operator
    }
}
```

```csharp
class C
{
    string M(Foo x)
    {
        return x == null ? null : x.Value;   // GM0144 — use null-conditional operator
    }
}
```

## Fix

```csharp
class C
{
    string M(Foo x)
    {
        return x?.Value;
    }
}
```

## Notes

- Applies to property access, field access, method calls, and element access (`[]`) on the checked expression.
- Only triggers when the null branch returns `null` literally and the non-null branch accesses a member of the checked expression.
- Equivalent to IDE0031 ("Use null propagation") from the .NET platform analyzers.
