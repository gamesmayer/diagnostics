# GM0141: continue statement is not allowed

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0141  |
| **Category** | Style   |
| **Severity** | Error   |
| **Default**  | Yes     |
| **Fixable**  | No      |
| **Settings** | No      |

## Description

The `continue` keyword adds complexity to code readability and should not be used. Restructure the loop body to avoid the need for `continue`.

## Violation

```csharp
class C
{
    void M(int[] items)
    {
        foreach (var item in items)
        {
            if (item == 0)
                continue;   // GM0141 — continue is not allowed

            Process(item);
        }
    }
}
```

## Fix

```csharp
class C
{
    void M(int[] items)
    {
        foreach (var item in items)
        {
            if (item != 0)
            {
                Process(item);
            }
        }
    }
}
```

## Notes

- The `continue` keyword adds complexity to code readability by creating multiple exit paths within a loop body.
- Restructure the loop logic using inverted conditions to eliminate the need for `continue`.
