# GM0124: Trailing commas are not allowed

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0124  |
| **Category** | Style   |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Disallows trailing commas in places where they are syntactically valid.

## Violation

```csharp
class C
{
    void M()
    {
        Foo(1, 2,);
    }

    void Foo(int a, int b) { }
}
```

## Fix

```csharp
class C
{
    void M()
    {
        Foo(1, 2);
    }

    void Foo(int a, int b) { }
}
```

## Notes

- The rule reports diagnostics on the trailing comma token.
- The rule applies to trailing commas before `)`, `]`, and `}`.
