# GM1213: An add accessor must appear before a remove accessor

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1213   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |

## Description

An `add` accessor appears after a `remove` accessor within an event declaration. The `add` accessor must always be declared first.

## Violation

```csharp
public event Action OnFoo
{
    remove { _onFoo -= value; }
    add    { _onFoo += value; } // GM1213
}
```

## Fix

```csharp
public event Action OnFoo
{
    add    { _onFoo += value; }
    remove { _onFoo -= value; }
}
```
