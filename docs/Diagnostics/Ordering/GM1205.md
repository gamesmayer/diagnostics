# GM1205: Partial element does not have an access modifier defined

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1205   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |

## Description

A partial class, struct, or interface does not have an access modifier. Partial elements must always declare an access modifier so that ordering rules can be applied consistently.

## Violation

```csharp
partial class Foo { } // GM1205
```

## Fix

```csharp
public partial class Foo { }
```
