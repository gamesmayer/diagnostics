# GM1200: Using directives must be placed outside namespace declarations

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1200   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

A `using` directive is placed inside a namespace declaration. Using directives should appear outside namespace declarations.

## Violation

```csharp
namespace MyApp
{
    using System; // GM1200
}
```

## Fix

```csharp
using System;

namespace MyApp
{
}
```
