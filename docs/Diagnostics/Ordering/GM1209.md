# GM1209: Using alias directives must be placed after other using directives

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1209   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |
| **Settings** | No      |

## Description

A `using` alias directive is positioned before a regular `using` directive. Using alias directives must appear after all non-alias using directives.

## Violation

```csharp
using Vec3 = UnityEngine.Vector3; // GM1209
using System;
```

## Fix

```csharp
using System;
using Vec3 = UnityEngine.Vector3;
```
