# GM1203: Constants must appear before fields

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1203   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |
| **Settings** | No      |

## Description

A constant field is placed beneath a non-constant field. Constants should be placed above fields to indicate that the two are fundamentally different types of elements.

## Violation

```csharp
public class Foo
{
    public int Value = 1;
    public const int Max = 100; // GM1203
}
```

## Fix

```csharp
public class Foo
{
    public const int Max = 100;
    public int Value = 1;
}
```
