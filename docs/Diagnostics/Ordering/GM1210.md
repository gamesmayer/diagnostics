# GM1210: Using directives must be ordered alphabetically by namespace

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1210   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |

## Description

The `using` directives within a C# code file are not sorted alphabetically by namespace. Within each group (System, non-System, static, alias) directives must be in ascending alphabetical order.

## Violation

```csharp
using UnityEngine;
using System.Collections; // GM1210
using System;
```

## Fix

```csharp
using System;
using System.Collections;
using UnityEngine;
```
