# GM1212: A get accessor must appear before a set accessor

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1212   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |
| **Settings** | No      |

## Description

A `get` accessor appears after a `set` or `init` accessor within a property or indexer. The `get` accessor must always be declared first.

## Violation

```csharp
public string Name
{
    set { _name = value; }
    get => _name; // GM1212
}
```

## Fix

```csharp
public string Name
{
    get => _name;
    set { _name = value; }
}
```
