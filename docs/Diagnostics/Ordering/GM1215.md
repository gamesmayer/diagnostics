# GM1215: Using static directives must be ordered alphabetically

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1215   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |

## Description

The `using static` directives within a C# code file are not sorted alphabetically by namespace.

## Violation

```csharp
using static UnityEngine.Physics;
using static System.Math; // GM1215 — 'System.Math' should come before 'UnityEngine.Physics'
```

## Fix

```csharp
using static System.Math;
using static UnityEngine.Physics;
```
