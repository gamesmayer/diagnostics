# GM1204: Static elements must appear before instance elements

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1204   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

A static element is placed beneath an instance element of the same type. Static elements should be placed above instance elements.

## Violation

```csharp
public class Foo
{
    public int InstanceField;
    public static int StaticField; // GM1204
}
```

## Fix

```csharp
public class Foo
{
    public static int StaticField;
    public int InstanceField;
}
```
