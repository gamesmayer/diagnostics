# GM1202: Elements must be ordered by access level

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1202   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |

## Description

Adjacent elements of the same kind must be ordered from most accessible to least accessible: `public` → `internal` → `protected internal` → `protected` → `private protected` → `private`.

## Violation

```csharp
public class Foo
{
    private int _x;    // GM1202 — private before public
    public int Y;
}
```

## Fix

```csharp
public class Foo
{
    public int Y;
    private int _x;
}
```
