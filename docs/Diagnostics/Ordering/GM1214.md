# GM1214: Readonly elements must appear before non-readonly elements

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1214   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Default**  | Yes      |
| **Fixable**  | No       |
| **Settings** | No      |

## Description

A `readonly` field is positioned beneath a non-`readonly` field of the same type. Readonly fields should be placed above non-readonly fields.

## Violation

```csharp
public class Foo
{
    public int Mutable;
    public readonly int Immutable; // GM1214
}
```

## Fix

```csharp
public class Foo
{
    public readonly int Immutable;
    public int Mutable;
}
```
