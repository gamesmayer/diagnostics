# GM0076: Avoid using Unity Debug.Log methods directly

| Property     | Value        |
| ------------ | ------------ |
| **ID**       | GM0076       |
| **Category** | Architecture |
| **Severity** | Warning      |
| **Default**  | Yes          |
| **Fixable**  | No           |
| **Settings** | No           |

## Description

Avoid using `UnityEngine.Debug.Log`, `UnityEngine.Debug.LogWarning`, and `UnityEngine.Debug.LogError` directly. Use `IAppLogger` abstractions instead.

## Violation

```csharp
using UnityEngine;

class Foo
{
    void M()
    {
        Debug.Log("Hello");
        Debug.LogWarning("Warn");
        Debug.LogError("Error");
    }
}
```

## Fix

```csharp
class Foo
{
    private readonly IAppLogger _logger;

    public Foo(IAppLogger logger)
    {
        _logger = logger;
    }

    void M()
    {
        _logger.Log("Hello");
        _logger.LogWarning("Warn");
        _logger.LogError("Error");
    }
}
```
