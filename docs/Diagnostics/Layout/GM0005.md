# GM0005: Attributes must not be separated by commas

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0005  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Attributes should be declared in separate brackets instead of being separated by commas in the same bracket.

## Violation

```csharp
[Serializable, Obsolete]
class Foo { }

[Obsolete, CLSCompliant(true)]
public void Method() { }
```

## Fix

```csharp
[Serializable]
[Obsolete]
class Foo { }

[Obsolete]
[CLSCompliant(true)]
public void Method() { }
```
