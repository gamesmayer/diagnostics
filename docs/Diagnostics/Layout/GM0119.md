# GM0119: No blank lines between array initializer items

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0119  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Items in an array initializer must not be separated by blank lines.

## Violation

```csharp
class C
{
    int[] arr = new int[]
    {
        0,
                    // GM0119 — blank line between items
        1
    };
}
```

## Fix

```csharp
class C
{
    int[] arr = new int[]
    {
        0,
        1
    };
}
```

## Notes

- The rule applies only to array initializers that are initial values of a declaration (field, local variable, or property). Array creation expressions used as arguments or return values are not checked.
- A diagnostic is reported on each blank line between consecutive items.
