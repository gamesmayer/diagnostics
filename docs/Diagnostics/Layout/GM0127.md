# GM0127: Each argument in a large argument list must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0127  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

When an argument list has at least the configured threshold of arguments, every argument must be on its own line for clarity. Applies to method calls, object creation expressions, and constructor initializers.

## Settings

| Parameter                             | Description                                                                                                       | Default |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------- |
| `dotnet_diagnostic.GM0127.threshold`  | Minimum number of arguments in a list required for GM0127 to report diagnostics. Must be greater than `1`.        | `4`     |

```ini
dotnet_diagnostic.GM0127.threshold = 4
```

With value `4`, GM0127 reports only argument lists with 4 or more arguments.

## Violation

```csharp
Method(arg1, arg2, arg3, arg4);

var x = new Foo(arg1, arg2, arg3, arg4);
```

All arguments are on the same line, but the list contains at least the threshold number of arguments.

## Fix

```csharp
Method(
    arg1,
    arg2,
    arg3,
    arg4);

var x = new Foo(
    arg1,
    arg2,
    arg3,
    arg4);
```

Each argument is now on its own line.

## Notes

- A diagnostic is reported on each argument (from the second onwards) that is on the same line as the previous argument.
- Argument lists with fewer arguments than the configured threshold do not trigger this diagnostic.
- Mixed-layout lists (where some arguments are already on their own line) are also reported — each violating argument is flagged individually.
- The code fix puts every argument after the first on a new line, using the indentation of the call's line plus four spaces.
