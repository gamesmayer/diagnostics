# GM0127: Each argument in a large argument list must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0127  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

When an argument list has at least the configured threshold of arguments, every argument must be on its own line for clarity. The same multiline requirement also applies when an argument contains a complex expression like a lambda, object initializer, or anonymous type. Applies to method calls and object creation expressions.

## Settings

| Parameter                            | Description                                                                                                | Default |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ------- |
| `dotnet_diagnostic.GM0127.threshold` | Minimum number of arguments in a list required for GM0127 to report diagnostics. Must be greater than `1`. | `4`     |

```ini
dotnet_diagnostic.GM0127.threshold = 4
```

With value `4`, GM0127 reports argument lists with 4 or more arguments, plus lists containing complex expressions like lambdas or object initializers.

## Violation

```csharp
Method(arg1, arg2, arg3, arg4);

var x = new Foo(arg1, arg2, arg3, arg4);

Method(x => x.ToString());

Method(new Item { Name = "test", Value = 42 });
```

All arguments are on the same line, and the list either contains at least the threshold number of arguments or includes a complex expression.

## Fix

```csharp
Method(
    arg1,
    arg2,
    arg3,
    arg4);

var x = new Foo(
    arg1,
    arg2,
    arg3,
    arg4);
```

Each argument is now on its own line.

## Notes

- A diagnostic is reported on each argument (from the second onwards) that is on the same line as the previous argument.
- Complex expressions (lambdas, object initializers, anonymous types) automatically trigger multiline layout enforcement, regardless of argument count.
- Argument lists with fewer arguments than the configured threshold do not trigger this diagnostic unless they contain complex expressions.
- Mixed-layout lists (where some arguments are already on their own line) are also reported — each violating argument is flagged individually.
- The code fix puts every argument after the first on a new line, using the indentation of the call's line plus four spaces.
