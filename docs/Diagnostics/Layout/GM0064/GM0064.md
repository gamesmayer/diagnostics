# GM0064: Early return in function

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0064  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | No      |
| **Settings** | No      |

## Description

Functions should have a single return statement at the end. Early return statements make control flow harder to follow and reason about.

## Violation

```csharp
int M(bool condition)
{
    if (condition)
        return 0;   // GM0064

    return 1;
}

void M(bool condition)
{
    if (condition)
        return;     // GM0064

    System.Console.WriteLine();
}
```

## Fix

```csharp
int M(bool condition)
{
    int result = 1;

    if (condition)
        result = 0;

    return result;
}

void M(bool condition)
{
    if (!condition)
        System.Console.WriteLine();
}
```
