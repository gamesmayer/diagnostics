# GM0044: No blank line between lambda arrow and body

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0044  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Lambda expressions must not contain blank lines between the `=>` token and the body.

Applies to both forms:

- Expression body (`x => x + 1`)
- Block body (`x => { return x + 1; }`)

## Violation

```csharp
System.Func<int, int> f = x =>

    x + 1;
```

```csharp
System.Func<int, int> f = x =>

{
    return x + 1;
};
```

## Fix

```csharp
System.Func<int, int> f = x =>
    x + 1;
```

```csharp
System.Func<int, int> f = x =>
{
    return x + 1;
};
```

## Notes

- A diagnostic is reported on the first blank line between `=>` and the lambda body.
- The rule is ignored when non-whitespace content (for example comments) exists between `=>` and the body.
- The code fix removes all blank lines between `=>` and the body while preserving body indentation.
