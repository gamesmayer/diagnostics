# GM0014: Namespace declaration must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0014  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

The namespace keyword and its identifier must appear on the same line. The entire namespace declaration must be written on a single line.

## Violation

```csharp
namespace  // GM0014 — namespace keyword and identifier on different lines
    Foo.Bar.Baz
{
}
```

```csharp
namespace Foo  // GM0014 — namespace name spans multiple lines
    .Bar
    .Baz
{
}
```

## Fix

```csharp
namespace Foo.Bar.Baz
{
}
```

## Notes

- Applies to both block-scoped (`namespace Foo { }`) and file-scoped (`namespace Foo;`) namespace declarations.
- The `namespace` keyword and the entire identifier (all dot-separated segments) must be written on the same line.
