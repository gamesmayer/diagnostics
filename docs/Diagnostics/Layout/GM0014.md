# GM0014: Namespace identifier must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0014  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Namespace identifiers must not span multiple lines. All segments of a qualified namespace name must appear on the same line.

## Violation

```csharp
namespace Foo  // GM0014 — namespace name spans multiple lines
    .Bar
    .Baz
{
}
```

## Fix

```csharp
namespace Foo.Bar.Baz
{
}
```

## Notes

- Applies to both block-scoped (`namespace Foo { }`) and file-scoped (`namespace Foo;`) namespace declarations.
- The entire namespace identifier (all dot-separated segments) must be written on a single line.
