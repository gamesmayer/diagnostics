# GM0117: Each item in array initializer must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0117  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Each item in the initializer of an array declaration must be on its own dedicated line. This rule only applies when the initializer spans multiple lines (open brace and close brace on different lines).

## Violation

```csharp
class C
{
    int[] arr = new int[]
    {
        0, 1  // GM0117 — 1 shares a line with 0
    };
}
```

## Fix

```csharp
class C
{
    int[] arr = new int[]
    {
        0,
        1
    };
}
```

## Notes

- The rule applies only to array initializers that are initial values of a declaration (field, local variable, or property). Array creation expressions used as arguments or return values are not checked.
- Single-line initializers (e.g., `new int[] { 0, 1 }`) are not checked.
- The first item is also checked against the opening brace line.
