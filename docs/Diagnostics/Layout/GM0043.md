# GM0043: Each operand in a multi-operand logical expression must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0043  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

In a logical expression (`||` or `&&`) with at least the configured threshold of operands, every operand must be on its own line for clarity.

## Settings

| Parameter                            | Description                                                                                                  | Default |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------- |
| `dotnet_diagnostic.GM0043.threshold` | Minimum number of operands in a logical expression required for GM0043 to report diagnostics. Must be greater than `1`. | `3`     |

```ini
dotnet_diagnostic.GM0043.threshold = 4
```

With value `4`, GM0043 reports only expressions with 4 or more operands.

## Violation

```csharp
bool result = a || b || c;
```

All three operands (`a`, `b`, `c`) are on the same line, but the expression contains at least the threshold number of operands.

## Fix

```csharp
bool result = a
    || b
    || c;
```

Each operand is now on its own line, preceded by its operator.

## Notes

- A diagnostic is reported on each operand (together with its preceding operator) that is not on its own line.
- An operand is considered to be on its own line when its preceding operator token is on a different line from the last token of the previous operand.
- Expressions with fewer operands than the configured threshold do not trigger this diagnostic.
- Mixed-layout expressions (where some operands are already on their own line) are also reported — each violating operand is flagged individually.
- Mixed-operator expressions (e.g. `a && b || c`) are evaluated per operator: the `||` chain and the `&&` chain are each checked independently.
- The code fix puts every operand after the first on a new line, using the indentation of the expression's line plus four spaces.
