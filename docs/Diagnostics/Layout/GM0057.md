# GM0057: No blank lines between declaration and first 'where' constraint clause

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0057  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A method or type declaration must not have blank lines between its header and the first `where` constraint clause.

## Violation

```csharp
public void Foo<T>()
                    // GM0057
    where T : System.IDisposable { }

public class Bar<T>
                    // GM0057
    where T : System.IDisposable
{
}
```

## Fix

```csharp
public void Foo<T>()
    where T : System.IDisposable { }

public class Bar<T>
    where T : System.IDisposable
{
}
```

## Notes

- Each blank line between the declaration and the first `where` clause produces a separate diagnostic.
- Lines containing only comments between the declaration and the first `where` clause are not flagged.
- This rule only applies to the gap before the **first** `where` clause. Use GM0055 for blank lines between consecutive `where` clauses.
