# GM0069: Properties not autoimplemented cannot be single line statements

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0069  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A property with non-autoimplemented accessors must not have its accessor list on a single line.

## Violation

```csharp
public List<string> WorldGateTaskIds { get => state.worldGateTaskIds; protected set => state.worldGateTaskIds = value; }  // GM0069
```

## Fix

```csharp
public List<string> WorldGateTaskIds
{
    get => state.worldGateTaskIds;
    protected set => state.worldGateTaskIds = value;
}
```

## Exception

Auto-implemented properties are not affected by this rule.

```csharp
public bool ShowLabel { get; private set; }  // OK
```
