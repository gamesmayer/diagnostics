# GM0080: Break statement must be preceded by a blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0080  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A break statement must be preceded by exactly one blank line when it is not the first statement in its block. This visually separates the break from the preceding logic, making it easier to identify the exit point of a block.

## Violation

```csharp
switch (value)
{
    case 1:
    {
        int x = DoSomething();
        break;  // GM0080
    }
}
```

## Fix

```csharp
switch (value)
{
    case 1:
    {
        int x = DoSomething();

        break;
    }
}
```

## Exception

A break statement that is the sole statement in its block does not require a preceding blank line.

```csharp
switch (value)
{
    case 1:
    {
        break;  // OK — sole statement
    }
}
```
