# GM0070: Each accessor must be on its own line in non-autoimplemented properties

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0070  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In a property with non-autoimplemented accessors, each accessor must be on its own line.

## Violation

```csharp
public List<string> WorldGateTaskIds
{
    get => state.worldGateTaskIds; protected set => state.worldGateTaskIds = value;  // GM0070
}
```

## Fix

```csharp
public List<string> WorldGateTaskIds
{
    get => state.worldGateTaskIds;
    protected set => state.worldGateTaskIds = value;
}
```

## Exception

Auto-implemented properties are not affected by this rule.

```csharp
public bool ShowLabel { get; private set; }  // OK
```
