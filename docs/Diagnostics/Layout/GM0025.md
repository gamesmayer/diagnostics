# GM0025: Each argument or parameter must be on its own line in a multi-line list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0025  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

When an argument or parameter list spans multiple lines, every item must be placed on its own dedicated line. No two arguments or parameters may share a line.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity, dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

The `entity` and `dialogueKey` arguments share a line, which violates the rule.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies when the argument or parameter list spans multiple lines (i.e., the opening and closing parentheses are on different lines).
- Single-line lists are not checked.
- Lists with a single item are not checked.
- A violation is reported when an argument or parameter shares a line with the immediately preceding argument or parameter.
- The diagnostic span covers the offending item and its trailing `','` separator, unless the item is the last in the list (no trailing separator), in which case only the item itself is highlighted.
- The expected indentation used for the code fix is one `indent_size` step deeper than the line containing the opening parenthesis (consistent with [GM0023](GM0023.md)).

## Configuration

The indent size is read from the standard `.editorconfig` property:

```ini
[*.cs]
indent_size = 4
```

If `indent_size` is not configured, it defaults to `4`.
