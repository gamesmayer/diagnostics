# GM0112: No blank lines between consecutive variables

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0112  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Consecutive local variable declarations must not be separated by blank lines.

## Violation

```csharp
class C
{
    void M()
    {
        int width = 1920;

        int height = 1080; // GM0112 reported on the blank line above
    }
}
```

## Fix

```csharp
class C
{
    void M()
    {
        int width = 1920;
        int height = 1080;
    }
}
```

## Notes

- The rule applies only to consecutive local variable declarations inside the same block.
- If another statement exists between declarations, the rule does not apply.
- A diagnostic is reported on each blank line between consecutive declarations.
