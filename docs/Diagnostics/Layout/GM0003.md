# GM0003: Attribute must be on the line immediately before the member

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0003  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Attributes must appear on the line directly preceding the member they annotate, with no blank lines in between.

## Violation

```csharp
[Obsolete]

public string Name { get; set; } // GM0003 reported on the blank line above
```

## Fix

```csharp
[Obsolete]
public string Name { get; set; }
```
