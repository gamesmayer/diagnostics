# GM0058: Inheritance list must be on the same line as the type declaration

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0058  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The inheritance list (the `:` symbol and all base types) must be on the same line as the type declaration identifier.

## Violation

```csharp
public class ShopModalController        // GM0058
    :
    ObservableController<ShopModalControllerState>, IEventRegistrable
{
}
```

## Fix

```csharp
public class ShopModalController : ObservableController<ShopModalControllerState>, IEventRegistrable
{
}
```
