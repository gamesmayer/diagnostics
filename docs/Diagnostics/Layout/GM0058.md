# GM0058: Colon must be on the same line as the declaration

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0058  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The `:` in inheritance clauses, `where` constraint clauses, and constructor initializers must be on the same line as the declaration.

## Violation

```csharp
// Inheritance clause colon on next line
class Foo
    : IFoo // GM0058
{
}

// Constructor initializer colon on next line
class Bar : Base
{
    Bar(int x)
        : base(x) { } // GM0058
}

// 'where' constraint clause colon on next line
class Baz
{
    void Foo<T>()
        where T
            : System.IDisposable { } // GM0058
}
```

## Fix

```csharp
class Foo : IFoo
{
}

class Bar : Base
{
    Bar(int x) : base(x) { }
}

class Baz
{
    void Foo<T>()
        where T : System.IDisposable { }
}
```

## Notes

- This rule applies to `BaseList`, `ConstructorInitializer` (`base`/`this`), and `TypeParameterConstraintClause` nodes.
- Use GM0086 and GM0087 to control spacing around the `:` once it is on the correct line.
