# GM0006: No blank lines between attributes on the same declaration

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0006  |
| **Category** | Style   |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Attributes that apply to the same declaration must not be separated by blank lines.

## Violation

```csharp
class Foo
{
    [Obsolete]

    [Serializable]
    public string Name { get; set; }
}
```

## Fix

```csharp
class Foo
{
    [Obsolete]
    [Serializable]
    public string Name { get; set; }
}
```
