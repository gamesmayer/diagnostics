# GM0137: Cast expression and its operand must be on the same line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0137  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The cast expression closing parenthesis and its operand must be on the same line with no line breaks between them.

> **Note:** Whether there should be a space between the cast expression and its operand is controlled by a separate rule.

## Violation

```csharp
var result = (PlayerType)
index;
```

The operand starts on a different line than the cast expression.

## Fix

```csharp
var result = (PlayerType)index;
```
