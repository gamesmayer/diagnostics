# GM1508: Closing brace must not be preceded by blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM1508  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

A closing brace within a C# element, statement, or expression must not be preceded by a blank line.

Ported from [SA1508](https://github.com/DotNetAnalyzers/StyleCopAnalyzers/blob/master/documentation/SA1508.md).

## Violation

```csharp
public bool Enabled
{
    get
    {
        return this.enabled;

    }

}
```

## Fix

```csharp
public bool Enabled
{
    get
    {
        return this.enabled;
    }
}
```
