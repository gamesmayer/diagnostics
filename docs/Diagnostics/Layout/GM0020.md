# GM0020: New line before open brace if braces are not empty

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0020  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Require opening braces to start on a new line when the brace enclosure is not empty.

## Violation

```csharp
class Foo {
    int value;
}
```

```csharp
void M() {
    int value = 1;
}
```

## Fix

```csharp
class Foo
{
    int value;
}
```

```csharp
void M()
{
    int value = 1;
}
```

## Notes

- This rule only applies to non-empty enclosures.
- Empty enclosure brace placement is handled by GM0021.

## Settings

Configure categories through `.editorconfig`:

```ini
dotnet_diagnostic.GM0020 = types, methods, properties, indexers, events, accessors, anonymous_methods, control_blocks, anonymous_types, object_collection_array_initializers, lambdas, local_functions
```

- Omit any category to skip it.
- Use `all` to enable all categories.
- Use `none` to disable all categories.
