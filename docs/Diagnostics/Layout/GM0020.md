# GM0020: Brace style for non-empty enclosures

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0020  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Require opening and closing braces of non-empty enclosures to match the configured brace style.

## Violation

Default behavior uses `Allman` style:

```csharp
class Foo {
    int value;
}
```

```csharp
void M() {
    int value = 1;
}
```

With `dotnet_diagnostic.GM0020.style = K&R`, this is also a violation:

```csharp
void M()
{
    int value = 1;
}
```

Regardless of style, this is also a violation because the closing brace is not on its own line:

```csharp
void M() {
    int value = 1; }
```

## Fix

Default behavior uses `Allman` style:

```csharp
class Foo
{
    int value;
}
```

```csharp
void M()
{
    int value = 1;
}
```

With `dotnet_diagnostic.GM0020.style = K&R`:

```csharp
void M() {
    int value = 1;
}
```

For a misplaced closing brace:

```csharp
void M() {
    int value = 1;
}
```

## Notes

- This rule only applies to non-empty enclosures.
- Empty enclosure brace placement is handled by GM0021.
- The default style is `Allman`.
- Supported styles are `Allman` and `K&R`.
- The `style` setting changes opening-brace placement; closing braces for non-empty enclosures must remain on their own line in both styles.

## Settings

Configure categories and style through `.editorconfig`:

```ini
dotnet_diagnostic.GM0020 = types, methods, properties, indexers, events, accessors, anonymous_methods, control_blocks, anonymous_types, object_collection_array_initializers, lambdas, local_functions
dotnet_diagnostic.GM0020.style = Allman
```

- Omit any category to skip it.
- Use `all` to enable all categories.
- Use `none` to disable all categories.
- Supported style values are `Allman` and `K&R`.
- Missing or invalid `style` values fall back to `Allman`.
