# GM0126: Each parameter in a large parameter list must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0126  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

When a parameter list has at least the configured threshold of parameters, every parameter must be on its own line for clarity.

## Settings

| Parameter                             | Description                                                                                                        | Default |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------- |
| `dotnet_diagnostic.GM0126.threshold`  | Minimum number of parameters in a list required for GM0126 to report diagnostics. Must be greater than `1`.        | `4`     |

```ini
dotnet_diagnostic.GM0126.threshold = 4
```

With value `4`, GM0126 reports only parameter lists with 4 or more parameters.

## Violation

```csharp
public void Method(int a, int b, int c, int d) { }
```

All four parameters are on the same line, but the list contains at least the threshold number of parameters.

## Fix

```csharp
public void Method(
    int a,
    int b,
    int c,
    int d) { }
```

Each parameter is now on its own line.

## Notes

- A diagnostic is reported on each parameter (from the second onwards) that is on the same line as the previous parameter.
- Parameter lists with fewer parameters than the configured threshold do not trigger this diagnostic.
- Mixed-layout lists (where some parameters are already on their own line) are also reported — each violating parameter is flagged individually.
- The code fix puts every parameter after the first on a new line, using the indentation of the declaration's line plus four spaces.
