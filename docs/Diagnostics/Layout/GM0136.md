# GM0136: Generic type argument list must be written on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0136  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The generic type argument list from `<` to `>` must be written on a single line.

## Violation

```csharp
PoolBinding.BindMonoPool<
    GameplayPlayerViewModel,
    GameplayPlayerView,
    PlayerType>();
```

The type argument list spans multiple lines.

## Fix

```csharp
PoolBinding.BindMonoPool<GameplayPlayerViewModel, GameplayPlayerView, PlayerType>();
```
