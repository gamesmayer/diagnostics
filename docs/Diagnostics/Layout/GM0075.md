# GM0075: #endif / #else / #elif directive must not be preceded by blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0075  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A `#endif`, `#else`, or `#elif` preprocessor directive must not be preceded by a blank line.

## Violation

```csharp
#if UNITY_EDITOR
CheckKeyboard();

#else
CheckSwipe();

#endif
```

## Fix

```csharp
#if UNITY_EDITOR
CheckKeyboard();
#else
CheckSwipe();
#endif
```
