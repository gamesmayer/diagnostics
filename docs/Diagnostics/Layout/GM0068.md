# GM0068: Multiple statements on one line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0068  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Multiple statements must not appear on the same line.

## Violation

```csharp
void M()
{
    int i = 0; adsMediator.AdsInitialized.AddListener(OnAdsInitialized);  // GM0068
}
```

## Fix

```csharp
void M()
{
    int i = 0;
    adsMediator.AdsInitialized.AddListener(OnAdsInitialized);
}
```

## Exception

Auto-implemented properties are not affected by this rule.

```csharp
public override AdsControllerEvents Events { get; set; }  // OK
```
