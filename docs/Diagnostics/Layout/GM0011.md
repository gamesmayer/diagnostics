# GM0011: No blank line at the beginning of file

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0011  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Files must not begin with a blank line.

## Violation

```csharp

using System; // GM0011 — blank line at the beginning of the file
class Foo { }
```

## Fix

```csharp
using System;
class Foo { }
```

## Notes

- Only blank lines at the very start of the file are flagged
- Blank lines elsewhere in the file are not affected by this rule
