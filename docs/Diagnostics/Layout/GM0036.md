# GM0036: Variable declaration header must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0036  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Variable declaration headers must be written on a single line.

The header includes:

- Type
- Identifier
- Assignment operator (`=`), when present

The assigned value may span multiple lines (for example, fluent chains or lambda expressions).

## Violation

```csharp
int
value = numbers
    .Where(x => x > 0)
    .Select(x => x * 2)
    .ToArray();
```

The declaration header (`int value =`) is split across lines.

## Fix

```csharp
int value = numbers
    .Where(x => x > 0)
    .Select(x => x * 2)
    .ToArray();
```

## Notes

- Diagnostics are reported over the complete declaration statement span, from the type token through the terminating semicolon (`;`).
- Declarations without an initializer are also expected to stay on one line.
