# GM0078: Block brace must be indented at the declaration level

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0078  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The opening and closing braces of a block must be indented at the same level as the containing declaration. A brace that is on the same line as the declaration (K&R style) is not checked.

## Violation

```csharp
void Method()
        {           // over-indented
    int x = 1;
        }           // over-indented
```

## Fix

```csharp
void Method()
{
    int x = 1;
}
```
