# GM0047: Multi-line assignment value must start on the same line as the assignment operator

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0047  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

In a multi-line assignment or variable declaration, the right-hand side value must begin on the same line as the `=` operator.

## Violation

```csharp
defaultCharacter =
                characters[0].key;

string x =
    "value";
```

The assignment value starts on a different line than `=`.

## Fix

```csharp
defaultCharacter = characters[0].key;

string x = "value";
```

The assignment value now starts on the same line as `=`.

## Notes

- Only triggered when the value starts on a different line than `=`.
- Does not apply to default parameter values or enum member declarations.
- Single-line assignments are not affected.
