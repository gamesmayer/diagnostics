# GM0002: Auto-implemented property must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0002  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Auto-implemented properties must not span multiple lines. When all accessors have no body, the entire property declaration must fit on one line.

## Violation

```csharp
public string Name
{
    get;
    set;
}
```

## Fix

```csharp
public string Name { get; set; }
```
