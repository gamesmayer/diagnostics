# GM0074: #if / #else / #elif directive must not be followed by blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0074  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A `#if`, `#else`, or `#elif` preprocessor directive must not be followed by a blank line.

## Violation

```csharp
#if UNITY_EDITOR

CheckKeyboard();
#else

CheckSwipe();
#endif
```

## Fix

```csharp
#if UNITY_EDITOR
CheckKeyboard();
#else
CheckSwipe();
#endif
```
