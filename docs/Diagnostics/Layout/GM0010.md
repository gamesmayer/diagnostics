# GM0010: No two consecutive blank lines

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0010  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Code must not contain two or more consecutive blank lines. At most one blank line is allowed between any two elements.

## Violation

```csharp
class Foo
{
    void A() { }


    void B() { } // GM0010 — two consecutive blank lines above
}
```

## Fix

```csharp
class Foo
{
    void A() { }

    void B() { }
}
```

## Notes

- This rule applies everywhere in a file: inside types, at the top level, and between namespaces
- A single blank line is allowed and is not flagged
- Three or more consecutive blank lines will produce one diagnostic per extra blank line
