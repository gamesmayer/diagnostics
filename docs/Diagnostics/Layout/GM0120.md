# GM0120: No blank lines between object initializer members

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0120  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Members in an object initializer must not be separated by blank lines.

## Violation

```csharp
var entry = new EditorConfigEntry
{
    directory = "",
                // GM0120 — blank line between members
    url = "https://example.com/.editorconfig",
};
```

## Fix

```csharp
var entry = new EditorConfigEntry
{
    directory = "",
    url = "https://example.com/.editorconfig",
};
```
