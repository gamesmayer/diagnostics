# GM0133: Constructor initializer must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0133  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Constructor initializer clauses (`base(...)` or `this(...)`) must be on their own line, not on the constructor declaration line.

## Violation

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x) : base(x)
    {
    }
}
```

The constructor initializer shares the line with the constructor declaration.

## Fix

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x) :
        base(x)
    {
    }
}
```

## Notes

- The rule applies to both `base(...)` and `this(...)` initializers.
- The colon position is handled by a separate diagnostic (GM0058), which requires the colon to remain on the same line as the constructor declaration.
