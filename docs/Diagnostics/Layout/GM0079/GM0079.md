# GM0079: No more than one space between tokens

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0079  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Adjacent tokens on the same line must be separated by at most one space.

## Violation

```csharp
public WalletSaveEntity SoftWallet    { get; }
```

## Fix

```csharp
public WalletSaveEntity SoftWallet { get; }
```
