# GM0007: Class members must be separated by a blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0007  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Class members must be separated by a blank line. This includes consecutive field declarations.

## Violation

```csharp
class C
{
    private int first;
    private int second; // GM0007
}
```

## Fix

```csharp
class C
{
    private int first;

    private int second;
}
```
