# GM0138: Lambda parameters and '=>' must be on the same line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0138  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

The lambda parameters and the `=>` token must be on the same line with no line breaks between them. Applies to both parenthesized and simple (single-parameter) lambda expressions.

## Violation

```csharp
list.Select((prefab, index)
                
                => (PlayerType)index);
```

The `=>` token is on a different line than the parameter list.

## Fix

```csharp
list.Select((prefab, index) => (PlayerType)index);
```
