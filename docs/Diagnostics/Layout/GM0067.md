# GM0067: Block statement must be followed by a blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0067  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A block-producing control flow statement (`if`, `switch`, `for`, `foreach`, `while`, `do`, `try`, `lock`, `using`) must be followed by exactly one blank line when it is not the last statement in its enclosing block.

## Violation

```csharp
if (!string.IsNullOrEmpty(Options.localeCode))
{
    i18n.SetLocale(Options.localeCode);
}
optionsLoadedEvent.Emit(...);  // GM0067
```

## Fix

```csharp
if (!string.IsNullOrEmpty(Options.localeCode))
{
    i18n.SetLocale(Options.localeCode);
}

optionsLoadedEvent.Emit(...);
```

## Exception

A block statement that is the last statement in its enclosing block does not require a trailing blank line.

```csharp
void M()
{
    if (condition)
    {
        DoSomething();
    }  // OK — last statement in block
}
```
