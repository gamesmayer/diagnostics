# GM0134: No blank line allowed around colon in inheritance clause

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0134  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In class and interface inheritance clauses, blank lines are not allowed before or after `:`.

## Violation

```csharp
interface IFoo { }

interface IBar

    :

    IFoo
{
}
```

There is a blank line before `:` and another blank line after `:`.

## Fix

```csharp
interface IFoo { }

interface IBar
    :
    IFoo
{
}
```

## Notes

- The rule only applies to class and interface inheritance clauses.
- This rule only removes blank lines; other inheritance-line placement rules are covered by separate diagnostics.
