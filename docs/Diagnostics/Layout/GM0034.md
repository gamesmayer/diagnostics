# GM0034: First item in multi-line argument/parameter list must start below opening parenthesis

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0034  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When an argument or parameter list spans multiple lines, the first item must not be on the same line as the opening parenthesis.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

The first item starts on the same line as `(`.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies to multi-line argument/parameter lists.
- A diagnostic is reported on the first item in the list.
- For parameters, the diagnostic span includes the parameter type and identifier.
- If the first item is not the last one, the diagnostic span includes the trailing comma separator.
- If the first item is also the last one, only the first item token span is reported.
