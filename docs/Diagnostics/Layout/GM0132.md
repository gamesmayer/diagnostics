# GM0132: Each parent class or interface in inheritance must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0132  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

In class and interface inheritance clauses, parent type line placement depends on `threshold`:

- When the number of parent types is greater than or equal to `threshold`, each parent type must be on its own line.
- When the number of parent types is lower than `threshold`, parent types must stay on the declaration line.

## Violation

```csharp
interface IFoo { }
interface IBar { }

interface IBaz : IFoo, IBar
{
}
```

With the default `threshold = 2`, this declaration has two parent interfaces, so each one must be on its own line.

## Fix

```csharp
interface IFoo { }
interface IBar { }

interface IBaz :
    IFoo,
    IBar
{
}
```

For low counts (for example, one parent with the default threshold), the expected form is on the declaration line:

```csharp
class Foo : Bar
{
}
```

## Notes

- The rule applies to class and interface declarations.
- `dotnet_diagnostic.GM0132.threshold` controls when multiline inheritance is required.
- Default value: `2`.

## Settings

### dotnet_diagnostic.GM0132.threshold

- Type: integer
- Default: `2`
- Meaning:
  - If inheritance parent count is greater than or equal to this value, each parent must be on its own line.
  - If inheritance parent count is lower than this value, parents must remain on the declaration line.
