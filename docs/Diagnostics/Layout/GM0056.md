# GM0056: 'where' constraint clause must be written on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0056  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Each `where` constraint clause must be written entirely on a single line. Line breaks between tokens of the clause are not allowed.

## Violation

```csharp
// Constraint split after colon
public void Foo<T>()
    where T :
        System.IDisposable { } // GM0056

// Constraint list split across lines
public void Foo<T>()
    where T : System.IDisposable,
        System.ICloneable { } // GM0056
```

## Fix

```csharp
public void Foo<T>()
    where T : System.IDisposable { }

public void Bar<T>()
    where T : System.IDisposable, System.ICloneable { }
```

## Notes

- This rule only checks that all tokens of a single `where` clause are on the same line. Use GM0053 to enforce that each clause is on its own line, and GM0054 to enforce correct indentation.
