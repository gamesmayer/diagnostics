# GM1505: Opening brace must not be followed by blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM1505  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

An opening brace within a C# element, statement, or expression must not be followed by a blank line.

Ported from [SA1505](https://github.com/DotNetAnalyzers/StyleCopAnalyzers/blob/master/documentation/SA1505.md).

## Violation

```csharp
public bool Enabled
{

    get
    {

        return this.enabled;
    }
}
```

## Fix

```csharp
public bool Enabled
{
    get
    {
        return this.enabled;
    }
}
```
