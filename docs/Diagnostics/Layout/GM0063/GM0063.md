# GM0063: Methods and lambda expressions with braces cannot be single line statements

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0063  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A method, constructor, destructor, operator, local function, or lambda expression whose body uses braces must not have the opening and closing brace on the same line. Empty blocks are excluded as they are controlled by a separate rule.

## Violation

```csharp
protected void OnDeltaAnimationComplete()
{ RefreshLabelLayoutElement(); }    // GM0063

Action a = () => { Console.WriteLine(); };  // GM0063
```

## Fix

```csharp
protected void OnDeltaAnimationComplete()
{
    RefreshLabelLayoutElement();
}

Action a = () =>
{
    Console.WriteLine();
};
```
