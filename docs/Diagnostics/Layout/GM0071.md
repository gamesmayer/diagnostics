# GM0071: Each accessor in non-autoimplemented properties must be separated by a blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0071  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In a property with non-autoimplemented accessors, each accessor must be separated from the previous one by a blank line.

## Violation

```csharp
public List<string> WorldGateTaskIds
{
    get => state.worldGateTaskIds;
    protected set => state.worldGateTaskIds = value;  // GM0071
}
```

## Fix

```csharp
public List<string> WorldGateTaskIds
{
    get => state.worldGateTaskIds;

    protected set => state.worldGateTaskIds = value;
}
```

## Exception

Auto-implemented properties are not affected by this rule.

```csharp
public bool ShowLabel { get; private set; }  // OK
```
