# GM0066: Block statement must be preceded by blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0066  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A block-producing control flow statement (`if`, `switch`, `for`, `foreach`, `while`, `do`, `try`, `lock`, `using`) must be preceded by exactly one blank line when it is not the first statement in its enclosing block.

## Violation

```csharp
PriceEntity price = priceSet.GetPrice(type);
bool canAfford = false;
if (price != null)  // GM0066
{
    canAfford = price.Amount <= balance;
}
```

## Fix

```csharp
PriceEntity price = priceSet.GetPrice(type);
bool canAfford = false;

if (price != null)
{
    canAfford = price.Amount <= balance;
}
```
