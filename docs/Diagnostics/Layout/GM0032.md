# GM0032: Single-line parameter or argument list must be on the declaration line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0032  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Declarations and invocations with a non-empty single-line argument or parameter list must keep the opening parenthesis on the same line as the declaration identifier.

## Violation

```csharp
void Reveal
(string worldKey, string gateKey)
{
}

Reveal
("world", "gate");
```

The parameter or argument list is written on a single line, but it starts on the line below the declaration.

## Fix

```csharp
void Reveal(string worldKey, string gateKey)
{
}

Reveal("world", "gate");
```

## Notes

- The rule applies only to non-empty lists that already fit on a single line.
- Empty lists are handled by GM0031.
- Multi-line lists are governed by the existing multi-line parenthesis and item-placement rules.
