# GM0053: Each 'where' constraint clause must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0053  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In method or type declarations with generic type parameters, each `where` constraint clause must be written on its own separate line.

## Violation

```csharp
// Method with constraint on same line as declaration
public void Foo<T>() where T : System.IDisposable { } // GM0053

// Multiple constraints on same line
public void Foo<T, U>()
    where T : System.IDisposable where U : System.ICloneable { } // GM0053
```

## Fix

```csharp
// Method with constraint on its own line
public void Foo<T>()
    where T : System.IDisposable { }

// Multiple constraints each on their own line
public void Foo<T, U>()
    where T : System.IDisposable
    where U : System.ICloneable { }
```
