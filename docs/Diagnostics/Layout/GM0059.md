# GM0059: Property/field access chain dot must be on the same line as the next identifier

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0059  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In a property or field access chain used as an assignment target, the dot must not appear at the end of a line. Move the dot to the beginning of the following line.

## Violation

```csharp
State
.Categories.        // GM0059
Value = categories.ToList();
```

## Fix

```csharp
State
.Categories
.Value = categories.ToList();
```
