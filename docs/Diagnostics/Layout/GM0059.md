# GM0059: Colon in named argument must be adjacent to parameter name

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0059  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When specifying a parameter name in a constructor or method call, the `:` symbol must be written immediately after the parameter identifier.

## Violation

```csharp
public override ShopModalControllerState InitialState => new
(
    categories
    : new List<ShopProductCategoryViewModel>() // GM0059
);
```

## Fix

```csharp
public override ShopModalControllerState InitialState => new
(
    categories: new List<ShopProductCategoryViewModel>()
);
```
