# GM0038: Fluent-chain segment indentation

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0038  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

In a multi-line fluent-chain statement, each segment's leading dot must be indented exactly one step to the right of the chain's starting indentation.

The "start indentation" is determined by the column of the first token of the chain expression.

## Violation

```csharp
var tasks = gateDefinition.UnlockingRule.Tasks
.Select(taskDefinition => new TaskEntity(taskDefinition))
    .ToList();
```

The `.Select` segment is at the same indentation level as `gateDefinition` (the chain start), and `.ToList()` is over-indented by two steps.

## Fix

```csharp
var tasks = gateDefinition.UnlockingRule.Tasks
    .Select(taskDefinition => new TaskEntity(taskDefinition))
    .ToList();
```

Each segment dot is indented exactly one step to the right of the chain's start indentation.

## Notes

- The rule only applies to fluent-chain segments that begin on a new line.
- Segments that continue on the same line as the previous expression are not checked.
- A diagnostic is reported on the dot token (`.`) of each offending segment.
- The code fix replaces the leading whitespace of the reported line with the correct indentation.
