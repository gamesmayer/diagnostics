# GM0018: Switch case clause declaration must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0018  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Switch case clause declarations must be written on a single line. No line breaks are allowed within the case clause (from the `case` keyword to the colon).

Applies to: `case <value>:` and `case <pattern>:` labels in switch statements.

## Violation

```csharp
switch (value)
{
    case  // GM0018 — case clause spans multiple lines
        SurfboardRewardEntity surfboardReward:
        break;
}
```

```csharp
switch (value)
{
    case  // GM0018 — case clause spans multiple lines
        1:
        break;
}
```

## Fix

```csharp
switch (value)
{
    case SurfboardRewardEntity surfboardReward:
        break;
}
```

```csharp
switch (value)
{
    case 1:
        break;
}
```

## Notes

- The diagnostic is reported on the full case clause span, from the `case` keyword to the colon.
- `default:` labels are never flagged as they consist of a single token.
