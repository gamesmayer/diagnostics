# GM0055: No blank lines between 'where' constraint clauses

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0055  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Consecutive `where` constraint clauses must not be separated by blank lines.

## Violation

```csharp
public void Foo<T, U>()
    where T : System.IDisposable
                                   // GM0055
    where U : System.ICloneable { }
```

## Fix

```csharp
public void Foo<T, U>()
    where T : System.IDisposable
    where U : System.ICloneable { }
```

## Notes

- Each blank line between consecutive `where` clauses produces a separate diagnostic.
- Lines containing only comments between `where` clauses are not flagged.
