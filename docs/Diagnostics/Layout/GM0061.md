# GM0061: Use '==' or '!=' instead of 'is' pattern for equality comparison

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0061  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Equality comparisons against `null` or constant values (enum members, `const` fields) should use `==` or `!=` instead of the `is` pattern.

## Violation

```csharp
x is null                                              // GM0061
x is not null                                          // GM0061
touch.phase is TouchPhase.Began                        // GM0061
touch.phase is not TouchPhase.Began                    // GM0061
touch.phase is TouchPhase.Moved or TouchPhase.Stationary  // GM0061
```

## Fix

```csharp
x == null
x != null
touch.phase == TouchPhase.Began
touch.phase != TouchPhase.Began
touch.phase == TouchPhase.Moved || touch.phase == TouchPhase.Stationary
```
