# GM0121: No blank line between constructor declaration and constructor initializer

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0121  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Constructor declarations must not contain blank lines between the parameter list and the `base` or `this` initializer.

## Violation

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x)

        : base(x)
    {
    }
}
```

There is a blank line between the parameter list and the constructor initializer.

## Fix

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x)
        : base(x)
    {
    }
}
```

## Notes

- The rule applies to both `base(...)` and `this(...)` initializers.
- Comments between the parameter list and the initializer do not trigger this rule.
