# GM0037: Parameter declaration header must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0037  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Parameter declaration headers must be written on a single line.

The header includes:

- Modifiers (for example, `ref`, `out`, `in`, `params`, `this`)
- Type, when present
- Identifier
- Assignment operator (`=`), when present

The default value expression may span multiple lines.

## Violation

```csharp
void M(int value
    = 1)
{
}
```

The parameter declaration header (`int value =`) is split across lines.

## Fix

```csharp
void M(int value = 1)
{
}
```

## Notes

- Diagnostics are reported over the complete parameter declaration span.
- Attribute placement is not part of this rule; line breaks after attributes are allowed.
