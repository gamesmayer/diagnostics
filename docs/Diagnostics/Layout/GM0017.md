# GM0017: Control structure clause declaration must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0017  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Control structure clause declarations must be written on a single line. No line breaks are allowed within the clause declaration (from the keyword to the closing parenthesis).

If keeping the clause on one line hurts readability, extract the condition/expression into a local variable and keep the clause declaration itself on one line.

Applies to: `if`, `foreach`, `for`, `while`, `do-while`, `switch`, `catch`, `lock`, and `using`.

## Violation

```csharp
if (  // GM0017 — clause declaration spans multiple lines
    isTrue)
{
}
```

```csharp
foreach (  // GM0017 — clause declaration spans multiple lines
    var i in items)
{
}
```

```csharp
try { }
catch (  // GM0017 — clause declaration spans multiple lines
    Exception ex)
{ }
```

## Fix

```csharp
if (isTrue)
{
}
```

```csharp
foreach (var i in items)
{
}
```

```csharp
try { }
catch (Exception ex) { }
```

## Notes

- The diagnostic is reported on the full clause declaration span, from the keyword to the closing parenthesis.
- Bare `catch` (without a declaration) is always a single token and is never flagged.
- For `do-while`, only the trailing `while (...)` clause is checked.
- For long conditions, prefer extracting the condition/expression to a local variable before the control structure.
