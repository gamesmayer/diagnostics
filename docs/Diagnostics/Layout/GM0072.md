# GM0072: Blank line required before #if directive

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0072  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A `#if` preprocessor directive must be preceded by a blank line unless it is the first statement in its enclosing block.

## Violation

```csharp
void M()
{
    int x = GetValue();
#if DEBUG  // GM0072
    System.Console.WriteLine(x);
#endif
}
```

## Fix

```csharp
void M()
{
    int x = GetValue();

#if DEBUG
    System.Console.WriteLine(x);
#endif
}
```
