# GM0031: Empty parentheses must be on the same line as the declaration

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0031  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Declarations and invocations without arguments or parameters must have the empty parentheses written on the same line as the declaration identifier.

## Violation

```csharp
void Foo
()
{
}

Foo
();
```

The empty parentheses `()` appear on a different line from the declaration.

## Fix

```csharp
void Foo()
{
}

Foo();
```

## Notes

- The rule applies to both parameter lists (method declarations, constructors, etc.) and argument lists (invocations) that have no parameters or arguments.
- A diagnostic is reported over the entire `()` span, from `(` to `)`.
- Multi-line empty parentheses such as `(\n)` are also flagged.
