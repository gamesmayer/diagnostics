# GM0050: No blank lines between multi-line operator-expression items

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0050  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Items in a multi-line operator expression must not be separated by blank lines.

## Violation

```csharp
return (gameplay && c.gameplay.Enabled) ||

    (showcase && c.showcase.Enabled) ||
    (dialogue && c.dialogue.Enabled);
```

There is a blank line between consecutive items in a multi-line operator expression.

## Fix

```csharp
return (gameplay && c.gameplay.Enabled) ||
    (showcase && c.showcase.Enabled) ||
    (dialogue && c.dialogue.Enabled);
```

## Notes

- A diagnostic is reported on each blank line between consecutive items.
- Comment lines between items are not considered blank lines.
- The code fix removes the reported blank line.
