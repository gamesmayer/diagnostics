# GM0135: All arguments must use named syntax when any argument is named

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0135  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

In a method or constructor call, if at least one argument uses named syntax (`name: value`), all arguments must use named syntax.

## Violation

```csharp
void Bar(int a, int b, int c) { }

Bar(1, b: 2, 3);
```

Arguments `1` and `3` are unnamed even though `b: 2` uses named syntax.

## Fix

```csharp
void Bar(int a, int b, int c) { }

Bar(a: 1, b: 2, c: 3);
```

## Notes

- The rule applies to both method invocations and constructor calls.
- If no argument in a call is named, this rule does not apply.
- `params` array elements are excluded from this rule.
