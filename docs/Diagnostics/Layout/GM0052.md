# GM0052: No blank lines between 'return' and returned expression

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0052  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A return statement with an expression must not contain blank lines between the `return` keyword and the returned expression.

## Violation

```csharp
return

settings.characters
    .Where(
        c => (gameplay && c.gameplay.Enabled) ||
            (showcase && c.showcase.Enabled) ||
            (dialogue && c.dialogue.Enabled)
    )
    .ToArray();
```

There is a blank line between `return` and the returned expression.

## Fix

```csharp
return
settings.characters
    .Where(
        c => (gameplay && c.gameplay.Enabled) ||
            (showcase && c.showcase.Enabled) ||
            (dialogue && c.dialogue.Enabled)
    )
    .ToArray();
```

## Notes

- A diagnostic is reported on each blank line between `return` and the returned expression.
- Comments between `return` and the expression are not considered blank lines.
- The code fix removes the reported blank line.
