# GM0015: No blank line between control structure clauses

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0015  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Control structure clauses must not be separated by blank lines. This applies to `else`/`else if` after an `if` block, `case`/`default` labels within a `switch`, and `catch`/`finally` after a `try` block.

## Violation

```csharp
if (condition)
{
}
           // GM0015 — blank line before else
else
{
}
```

```csharp
switch (x)
{
    case 1:
    {
        break;
    }
           // GM0015 — blank line before next case
    case 2:
    {
        break;
    }
}
```

```csharp
try
{
}
           // GM0015 — blank line before catch
catch
{
}
```

## Fix

```csharp
if (condition)
{
}
else
{
}
```

```csharp
switch (x)
{
    case 1:
    {
        break;
    }
    case 2:
    {
        break;
    }
}
```

```csharp
try
{
}
catch
{
}
```

## Notes

- Applies to: `else`, `else if`, `case`, `default`, `catch`, `finally`
- Multiple blank lines between clauses are each flagged individually
