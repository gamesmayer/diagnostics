# GM0013: Switch case block must be wrapped in braces

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0013  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

A switch case code block must be wrapped in braces, including the break statement.

## Violation

```csharp
switch (x)
{
    case 1:
        DoSomething(); // GM0013 — not wrapped in braces
        break;
}
```

## Fix

```csharp
switch (x)
{
    case 1:
    {
        DoSomething();
        break;
    }
}
```

## Notes

- Applies to all switch sections: `case`, `default`, and fall-through labels.
- The `break` (or `return`, `throw`, etc.) statement must be inside the braces along with the rest of the case body.
- Empty fall-through cases (no statements) are not flagged.
