# GM0046: Binary operator in multi-line expression must be at the end of the previous line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0046  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

In a multi-line expression, binary operators must appear at the end of the previous operand's line, not at the beginning of the next line.

Applies to: `+`, `-`, `*`, `/`, `%`, `&&`, `||`, `&`, `|`, `^`, `<<`, `>>`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `??`

## Violation

```csharp
bool isEmpty = characters != null
            && characters.Length > 0
            && string.IsNullOrEmpty(defaultCharacter);

int x = 0 +
    1 -
    2
    * 3;
```

Operators are at the beginning of the next line instead of the end of the previous line.

## Fix

```csharp
bool isEmpty = characters != null &&
            characters.Length > 0 &&
            string.IsNullOrEmpty(defaultCharacter);

int x = 0 +
    1 -
    2 *
    3;
```

Operators now appear at the end of each preceding line.

## Notes

- Only triggered when the operator is on a different line than the previous operand's last token.
- Single-line expressions are not affected.
