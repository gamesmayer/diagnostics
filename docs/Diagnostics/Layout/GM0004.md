# GM0004: Member declaration must be on a new line after its attributes

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0004  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Member declarations must start on a new line following their attributes. An attribute and the member it decorates must not appear on the same line.

## Violation

```csharp
[Obsolete] public string Name { get; set; } // GM0004 reported on 'public'
```

## Fix

```csharp
[Obsolete]
public string Name { get; set; }
```
