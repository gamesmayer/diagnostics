# GM0026: Closing parenthesis in multi-line argument/parameter list must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0026  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

When an argument or parameter list spans multiple lines, the closing parenthesis must be written on its own line directly below the last item.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled);
```

The closing parenthesis `)` is on the same line as the last argument.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies to multi-line argument/parameter lists.
- A diagnostic is reported only on the closing parenthesis token `)`.
- A diagnostic is only fired when `)` is on the same line as the last argument/parameter item. Blank lines between the last item and `)` are allowed.
