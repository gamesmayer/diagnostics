# GM0118: Comma must be on the same line as the previous token

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0118  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Commas must be placed at the end of the preceding item, not at the beginning of the next line or on their own line. Orphan commas — commas that appear on a line of their own or at the start of the next item's line — are not allowed.

## Violation

Comma on its own line:

```csharp
GUILayout.Label
(
    "Run C# linting on your source code."
    ,
    EditorStyles.helpBox
);
```

Comma at the beginning of the next item's line:

```csharp
GUILayout.Label
(
    "Run C# linting on your source code."
    , EditorStyles.helpBox
);
```

## Fix

```csharp
GUILayout.Label
(
    "Run C# linting on your source code.",
    EditorStyles.helpBox
);
```

## Notes

- The rule applies to argument lists, parameter lists, attribute argument lists, type argument lists, and type parameter lists.
- A diagnostic is reported on the comma token itself.
