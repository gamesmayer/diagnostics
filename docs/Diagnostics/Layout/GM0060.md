# GM0060: Property/field access chain must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0060  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A property or field access chain used as an assignment target must be written entirely on a single line.

## Violation

```csharp
State
.Categories.        // GM0060
Value = categories.ToList();
```

## Fix

```csharp
State.Categories.Value = categories.ToList();
```
