# GM0030: Prevent blank line between declaration and opening parenthesis

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0030  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When an argument or parameter list places the opening parenthesis on a separate line, there must not be a blank line between the declaration and the opening parenthesis.

## Violation

```csharp
state = new SkipDialogueLineAnswerState

(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

A blank line appears between the declaration and the opening parenthesis `(`.

## Fix

```csharp
state = new SkipDialogueLineAnswerState
(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule applies to argument/parameter lists where the opening parenthesis is on a separate line.
- A diagnostic is reported on the first blank line between the declaration and the opening parenthesis.
- The rule ignores cases where there is non-whitespace content (for example, comments) between declaration and opening parenthesis.
