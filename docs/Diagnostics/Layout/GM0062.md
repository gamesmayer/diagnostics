# GM0062: Use 'is or' syntax for multiple type checks on the same expression

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0062  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Type checking expressions that test the same variable against multiple types using `||` should use the `is or` syntax instead.

## Violation

```csharp
n is EntityA || n is EntityB                          // GM0062
n is EntityA || n is EntityB || n is EntityC          // GM0062
```

## Fix

```csharp
n is EntityA or EntityB
n is EntityA or EntityB or EntityC
```
