# GM0073: Blank line required after #endif directive

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0073  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A `#endif` preprocessor directive must be followed by a blank line unless it is the last statement in its enclosing block.

## Violation

```csharp
void M()
{
#if DEBUG
    System.Console.WriteLine();
#endif  // GM0073
    int x = GetValue();
}
```

## Fix

```csharp
void M()
{
#if DEBUG
    System.Console.WriteLine();
#endif

    int x = GetValue();
}
```
