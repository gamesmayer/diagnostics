# GM0042: Blank line required after last using directive

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0042  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A blank line is required between the last using directive and the next declaration.

## Violation

```csharp
using System;
using System.Collections;
class Foo { } // GM0042 reported on 'class'
```

## Fix

```csharp
using System;
using System.Collections;

class Foo { }
```
