# GM0012: No blank line before opening brace

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0012  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

An opening brace must not be preceded by a blank line.

## Violation

```csharp
class Foo
           // GM0012 — blank line before opening brace
{
}
```

## Fix

```csharp
class Foo
{
}
```

## Notes

- Applies to all block constructs: class, namespace, method, if/else, for, while, foreach, etc.
- Only the blank line immediately before the `{` line is flagged
