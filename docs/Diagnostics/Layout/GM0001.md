# GM0001: No blank lines between consecutive using directives

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0001  |
| **Category** | Style   |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Consecutive `using` directives must not be separated by blank lines.

## Violation

```csharp
using System;

using UnityEngine; // GM0001 reported on the blank line above
```

## Fix

```csharp
using System;
using UnityEngine;
```
