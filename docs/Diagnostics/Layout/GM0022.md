# GM0022: New line required before opening brace for empty enclosure

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0022  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Require opening braces of empty enclosures to be on a new line (Allman style).

## Violation

```csharp
void M() { }
```

```csharp
if (condition) { }
```

## Fix

```csharp
void M()
{ }
```

```csharp
if (condition)
{ }
```

## Notes

- This rule only applies to empty enclosures.
- Non-empty enclosure brace placement is handled by GM0020.
- This rule is the Allman-style counterpart of GM0021, which requires the opening brace to stay on the declaration line.

## Configuration

Configure categories through `.editorconfig`:

```ini
dotnet_diagnostic.GM0022 = types, methods, properties, indexers, events, accessors, anonymous_methods, control_blocks, anonymous_types, object_collection_array_initializers, lambdas, local_functions
```

- Omit any category to skip it.
- Use `all` to enable all categories.
- Use `none` to disable all categories.
