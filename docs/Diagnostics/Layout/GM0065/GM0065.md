# GM0065: Return statement must be preceded by a blank line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0065  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

A return statement must be preceded by exactly one blank line when it is not the first (and only) statement in its block. This visually separates the return from the preceding logic, making it easier to identify the exit point of a block.

## Violation

```csharp
bool IsUnlocked()
{
    bool isUnlocked = characterSave?.IsUnlocked ?? false;
    return isUnlocked;  // GM0065
}
```

## Fix

```csharp
bool IsUnlocked()
{
    bool isUnlocked = characterSave?.IsUnlocked ?? false;

    return isUnlocked;
}
```

## Exception

A return statement that is the sole statement in its block does not require a preceding blank line.

```csharp
bool IsUnlocked()
{
    return characterSave?.IsUnlocked ?? false;  // OK — sole statement
}
```
