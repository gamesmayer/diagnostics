# GM0019: Empty braces enclosure must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0019  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Empty enclosure braces must be written on a single line with a single space between them.

Applies to all empty brace enclosures, including:

- Type declarations (`class`, `struct`, `interface`, `record`, `enum`, `namespace`)
- Method, constructor, destructor, operator, and local function bodies
- Property, indexer, event accessor lists and accessor bodies
- Control blocks (`if`, `else`, `for`, `foreach`, `while`, `do`, `using`, `lock`, `fixed`, `checked`, `unsafe`, `switch`, `try`, `catch`, `finally`)
- Lambda and anonymous method bodies
- Object, collection, and array initializers
- Anonymous object creation expressions

## Violation

```csharp
class Foo :
    IDisposable
{} // GM0019
```

```csharp
protected void Method(
    int a,
    int b,
    int c
)
{  } // GM0019
```

```csharp
if (condition)
{
} // GM0019
```

## Fix

```csharp
class Foo :
    IDisposable
{ }
```

```csharp
protected void Method(
    int a,
    int b,
    int c
)
{ }
```

```csharp
if (condition) { }
```

## Notes

- The declaration can span multiple lines; this rule only checks the brace enclosure itself.
- Only empty bodies are flagged.
