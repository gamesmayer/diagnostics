# GM0019: Empty braces enclosure must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0019  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Empty class and method body braces must be written on a single line.

Applies to:

- `class` declarations with an empty body.
- `method` declarations with an empty body.

## Violation

```csharp
class Foo :
    IDisposable
{} // GM0019
```

```csharp
protected void Method(
    int a,
    int b,
    int c
)
{  } // GM0019
```

## Fix

```csharp
class Foo :
    IDisposable
{ }
```

```csharp
protected void Method(
    int a,
    int b,
    int c
)
{ }
```

## Notes

- The declaration can span multiple lines; this rule only checks the brace enclosure itself.
- Only empty bodies are flagged.
