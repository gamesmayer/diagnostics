# GM0008: No blank lines within argument or parameter lists

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM0008   |
| **Category** | Layout   |
| **Severity** | Warning  |
| **Fixable**  | Yes      |
| **Settings** | No      |

## Description

Disallows blank lines within invocation argument lists and method declaration parameter lists.
When arguments or parameters are split across multiple lines, they must appear as a continuous block without vertical spacing.

## Violation

```csharp
Calculate(
    10,

    20); // GM0008

public void Foo(
    int a,

    int b)
{
}
```

## Fix

```csharp
Calculate(
    10,
    20);

public void Foo(
    int a,
    int b)
{
}
```
