# GM0021: Empty enclosure opening brace must stay on declaration line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0021  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |

## Description

Require opening braces of empty enclosures to stay on the declaration line.

## Violation

```csharp
void M()
{ }
```

```csharp
if (condition)
{ }
```

## Fix

```csharp
void M() { }
```

```csharp
if (condition) { }
```

## Notes

- This rule only applies to empty enclosures.
- Non-empty enclosure brace placement is handled by GM0020.

## Configuration

Configure categories through `.editorconfig`:

```ini
dotnet_diagnostic.GM0021 = types, methods, properties, indexers, events, accessors, anonymous_methods, control_blocks, anonymous_types, object_collection_array_initializers, lambdas, local_functions
```

- Omit any category to skip it.
- Use `all` to enable all categories.
- Use `none` to disable all categories.
