# GM0139: Type expression must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0139  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Type expressions such as generic names (e.g., `List<T>`) and array types (e.g., `MyType[]`) must be written on a single line without line breaks.

## Violation

```csharp
var list = new List
    <TaskProgressEntity>();
```

The identifier `List` and the `<` of the type argument list are on different lines.

```csharp
public string
    [] Field;
```

The element type `string` and the `[` of the rank specifier are on different lines.

## Fix

```csharp
var list = new List<TaskProgressEntity>();
```

```csharp
public string[] Field;
```

The type expression is now written on a single line.
