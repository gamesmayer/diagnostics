# GM0128: new keyword and type must be on the same line in object creation

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0128  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

In an object creation expression, the `new` keyword and the type must be on the same line.

## Violation

```csharp
_blackBg = new
    Texture2D(1, 1);
```

The `new` keyword and `Texture2D` are on different lines.

## Fix

```csharp
_blackBg = new Texture2D(1, 1);
```

The `new` keyword and the type are now on the same line.
