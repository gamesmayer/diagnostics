# GM0016: Attribute must be on a single line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0016  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Attributes must be declared on a single line. No line breaks are allowed between the opening `[` and closing `]` of an attribute.

## Violation

```csharp
[  // GM0016 — attribute spans multiple lines
    System.Obsolete
]
class Foo { }
```

```csharp
class Foo
{
    [  // GM0016 — attribute spans multiple lines
        System.Obsolete("Use Bar instead")
    ]
    void Method() { }
}
```

## Fix

```csharp
[System.Obsolete]
class Foo { }
```

```csharp
class Foo
{
    [System.Obsolete("Use Bar instead")]
    void Method() { }
}
```

## Notes

- Applies to all attribute lists on any declaration (class, method, property, field, parameter, etc.).
- The entire content between `[` and `]` must appear on the same line.
