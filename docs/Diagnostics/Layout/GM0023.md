# GM0023: Misaligned parameter or argument in multi-line list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0023  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

When arguments or parameters are each on their own line, they must be indented by one step relative to the containing statement.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

The `dialogueKey` argument is not indented by one step relative to the `new` expression line.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies when the first argument or parameter is on a different line from the opening parenthesis (hanging indent style).
- If the first argument is on the same line as the opening parenthesis, the rule does not apply.
- Each argument or parameter on its own line is checked independently; a diagnostic is reported for every misaligned item.
- The expected indentation is one `indent_size` step deeper than the indentation of the line containing the opening parenthesis.

## Settings

The indent size is read from the standard `.editorconfig` property:

```ini
[*.cs]
indent_size = 4
```

If `indent_size` is not configured, it defaults to `4`.
