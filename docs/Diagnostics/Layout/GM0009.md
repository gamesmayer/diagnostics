# GM0009: No line breaks between modifiers, type, and identifier

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0009  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Fixable**  | Yes     |

## Description

Class declarations and class member declarations must not have line breaks between modifiers, type, and identifier. All components of the declaration signature (modifiers, return type, and identifier) should appear on the same line.

## Violation

```csharp
// Class declaration
public
class Foo // GM0009
{
}

// Field declaration
private
int field; // GM0009

// Property declaration
public
int Property { get; set; } // GM0009

// Method declaration
public void
Method() { } // GM0009

// Multiple modifiers
public
sealed
class Bar // GM0009
{
}
```

## Fix

```csharp
// Class declaration
public class Foo
{
}

// Field declaration
private int field;

// Property declaration
public int Property { get; set; }

// Method declaration
public void Method() { }

// Multiple modifiers
public sealed class Bar
{
}
```

## Notes

- This rule applies to classes, structs, records, interfaces, and all class members (fields, properties, methods, events, constructors)
- Attributes are excluded from this check - line breaks after attributes are allowed
- The declaration body (after the identifier) can still span multiple lines
