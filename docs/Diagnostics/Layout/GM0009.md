# GM0009: No line breaks in declaration header

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0009  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Class declarations and class member declarations must not have line breaks in the declaration header.

For member declarations with initializers, the declaration header also includes the assignment operator (`=`).

## Violation

```csharp
// Class declaration
public
class Foo // GM0009
{
}

// Field declaration
private
int field; // GM0009

// Field initializer header
private int field
= 1; // GM0009

// Property declaration
public
int Property { get; set; } // GM0009

// Property initializer header
public int Property
= 1; // GM0009

// Method declaration
public void
Method() { } // GM0009

// Multiple modifiers
public
sealed
class Bar // GM0009
{
}
```

## Fix

```csharp
// Class declaration
public class Foo
{
}

// Field declaration
private int field;

// Field initializer header
private int field = 1;

// Property declaration
public int Property { get; set; }

// Property initializer header
public int Property = 1;

// Method declaration
public void Method() { }

// Multiple modifiers
public sealed class Bar
{
}
```

## Notes

- This rule applies to classes, structs, records, interfaces, and all class members (fields, properties, methods, events, constructors)
- Attributes are excluded from this check - line breaks after attributes are allowed
- For member declarations with initializers, the value expression (after `=`) can still span multiple lines
