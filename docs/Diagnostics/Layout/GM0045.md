# GM0045: Lambda expression body must be indented one step from the arrow line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0045  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

When a lambda expression body (without braces) is on a different line from the `=>` token, it must be indented exactly one step (4 spaces) more than the leading whitespace of the `=>` line.

## Violation

```csharp
System.Func<int, int> f = x =>
x + 1;
```

The body `x + 1` is on a new line but not indented relative to the `=>` line.

## Fix

```csharp
System.Func<int, int> f = x =>
    x + 1;
```

The body is now indented one step from the `=>` line.

## Notes

- Only applies to expression bodies (lambdas without braces).
- If the body is on the same line as `=>`, this rule does not apply.
- The expected indentation is the leading whitespace of the `=>` line plus 4 spaces.
