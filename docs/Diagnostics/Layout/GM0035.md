# GM0035: No blank lines between fluent-chain segments

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0035  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

Consecutive segments in a fluent-chain statement must not be separated by blank lines.

## Violation

```csharp
var values = source
    .Where(x => x > 1)

    .Select(x => x * 2)
    .ToList();
```

There is a blank line between consecutive segments in the fluent chain.

## Fix

```csharp
var values = source
    .Where(x => x > 1)
    .Select(x => x * 2)
    .ToList();
```

## Notes

- A diagnostic is reported on each blank line between fluent-chain segments.
- Comments between segments are not considered blank lines.
- The code fix removes the reported blank line.
