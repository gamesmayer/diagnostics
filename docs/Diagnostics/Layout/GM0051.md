# GM0051: Return expression must start on the same line as 'return'

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0051  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |

## Description

In a multi-line return statement, the returned expression must begin on the same line as the `return` keyword.

## Violation

```csharp
return
    value;

return
    characters[0].key;
```

The return expression starts on a different line than `return`.

## Fix

```csharp
return value;

return characters[0].key;
```

The return expression now starts on the same line as `return`.

## Notes

- Triggered only when a return expression starts on a different line than `return`.
- `return;` statements (without an expression) are not affected.
- Multi-line expressions are allowed as long as the expression starts on the `return` line.
