# GM0123: Each member in object initializer must be on its own line

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0123  |
| **Category** | Layout  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Each member in an object initializer must be on its own dedicated line.

## Violation

```csharp
var entry = new EditorConfigEntry
{
    directory = "", url = "https://...",  // GM0123 — members on same line
};
```

## Fix

```csharp
var entry = new EditorConfigEntry
{
    directory = "",
    url = "https://...",
};
```

## Notes

- Single-line initializers (`new Foo { A = 1, B = 2 }`) are not checked.
- The first member on the same line as `{` is also flagged.
- The fix inserts a newline and indentation matching the `new` keyword line indent plus one `indent_size` step (default 4 spaces).
