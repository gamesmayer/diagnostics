# GM0024: Parent type in inheritance must be indented one step from the declaration

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0024      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Each parent class or interface in a class or interface inheritance clause must be indented exactly one step to the right of the declaration. The indent step is determined by the `indent_size` EditorConfig setting, defaulting to 4 spaces.

## Violation

```csharp
interface IFoo { }
interface IBar { }

interface IBaz :
IFoo,
        IBar
{
}
```

The inherited interfaces are not indented one step from the declaration.

## Fix

```csharp
interface IFoo { }
interface IBar { }

interface IBaz :
    IFoo,
    IBar
{
}
```

## Notes

- This rule only applies when the parent type is already on its own line.
- Use `GM0132` to enforce that each parent type is placed on its own line.
