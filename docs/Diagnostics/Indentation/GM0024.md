# GM0024: Anonymous function incorrectly indented

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0024  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

Braces of an anonymous function must be at the same indentation level as the declaration line, and statements inside must be indented one step further — just like any other function body.

Applies to:

- Lambda expressions with block bodies (`() => { }`, `x => { }`)
- Anonymous method expressions (`delegate { }`)

## Violation

```csharp
Action action = () =>
    { // GM0024: brace indented too much
        return;
    };
```

```csharp
Action action = () =>
{
return; // GM0024: statement not indented
};
```

```csharp
Action action = () =>
{
    return;
        }; // GM0024: closing brace indented too much
```

## Fix

```csharp
Action action = () =>
{
    return;
};
```

## Notes

- The rule only applies when the opening brace `{` is on a different line from the `=>` or `delegate` keyword. Inline forms like `() => { return; }` are not checked.
- Only direct statements of the anonymous function body are checked for indentation; inner blocks are not recursively validated by this rule.
- The expected indentation is computed from the line containing the `=>` or `delegate` keyword.

## Settings

The indent size is read from the standard `.editorconfig` property:

```ini
[*.cs]
indent_size = 4
```

If `indent_size` is not configured, it defaults to `4`.
