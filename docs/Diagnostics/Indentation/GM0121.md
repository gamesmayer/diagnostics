# GM0121: Object initializer braces must be indented at the declaration level

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0121      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Opening and closing braces of an object initializer must be indented at the same level as the line containing the `new` keyword.

## Violation

```csharp
var entry = new EditorConfigEntry
    {                           // GM0121 — over-indented open brace
        directory = "",
        url = "https://example.com/.editorconfig",
    };                          // GM0121 — over-indented close brace
```

## Fix

```csharp
var entry = new EditorConfigEntry
{
    directory = "",
    url = "https://example.com/.editorconfig",
};
```

## Notes

- The rule applies to both `new TypeName { }` and `new() { }` (implicit object creation) syntax.
- If the opening brace is on the same line as the `new` keyword, no diagnostic is reported for that brace.
- Each misindented brace produces an individual diagnostic.
