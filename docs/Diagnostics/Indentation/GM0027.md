# GM0027: Opening parenthesis placement in multi-line argument/parameter list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0027  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | No      |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When an argument or parameter list spans multiple lines, the opening parenthesis must stay on the declaration line and the first item must begin below.

Like parenthesis K&R indentation style.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

The opening parenthesis `(` is not followed by a line break before the first argument.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies to multi-line argument/parameter lists.
- A diagnostic is reported only on the opening parenthesis token `(`.
- The opening parenthesis must remain on the declaration line.
- The first argument or parameter must start on the line immediately after `(`, or on any later line (blank lines between `(` and the first item are allowed).
- A diagnostic is only fired when the first item starts on the same line as `(`.
