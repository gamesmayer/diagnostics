# GM0081: Case labels must be indented one step right from the switch keyword

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0081  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Case labels (including `default`) in a switch statement must be indented exactly one step right from the `switch` keyword. The indent step is inferred from the switch statement's own indentation relative to its enclosing block, defaulting to 4 spaces.

## Violation

```csharp
switch (value)
{
case 1:          // GM0081 — not indented
    DoSomething();
    break;
        case 2:  // GM0081 — over-indented
    DoSomethingElse();
    break;
default:         // GM0081 — not indented
    break;
}
```

## Fix

```csharp
switch (value)
{
    case 1:
        DoSomething();
        break;
    case 2:
        DoSomethingElse();
        break;
    default:
        break;
}
```
