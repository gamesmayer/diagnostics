# GM0029: Opening parenthesis must be on a new line in multi-line list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0029  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When an argument or parameter list spans multiple lines, the opening parenthesis must be placed on a separate line below the declaration (Allman style).

This is the Allman-style counterpart to [GM0027](GM0027.md), which enforces K&R style (parenthesis on the declaration line).

## Violation

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

The opening parenthesis `(` is on the same line as the declaration instead of on a new line below it.

## Fix

```csharp
state = new SkipDialogueLineAnswerState
(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies to multi-line argument/parameter lists.
- A diagnostic is reported only on the opening parenthesis token `(`.
- The opening parenthesis must be on a separate line below the declaration (not on the same line as the identifier or keyword that precedes it).
- This rule is mutually exclusive with [GM0027](GM0027.md) — enable only one at a time depending on the preferred style.
- Similar to [GM0027](GM0027.md) but enforces Allman indentation style rather than K&R for the opening parenthesis.
