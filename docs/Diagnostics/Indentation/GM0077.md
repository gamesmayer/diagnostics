# GM0077: Contents inside braces must be indented one step

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0077      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Statements inside blocks, members inside type bodies, accessors inside accessor lists, and statements inside lambda/anonymous method block bodies must be indented by exactly one step relative to the indentation of the containing declaration line. This mirrors the behavior of the `csharp_indent_block_contents = true` EditorConfig setting as an enforced diagnostic.

## Violation

```csharp
class Foo
{
    int Value
    {
get;
        set;
    }

void Method()
{
int x = 1;
int y = 2;
}
}
```

## Fix

```csharp
class Foo
{
    int Value
    {
        get;
        set;
    }

    void Method()
    {
        int x = 1;
        int y = 2;
    }
}
```
