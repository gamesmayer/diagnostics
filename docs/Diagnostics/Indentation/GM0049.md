# GM0049: Wrapped operator-expression item indentation

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0049  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | Yes     |

## Description

In a multi-line operator expression, each wrapped item must be indented exactly one step to the right of the expression start line.

This rule applies to the same operators as GM0046:
`+`, `-`, `*`, `/`, `%`, `&&`, `||`, `&`, `|`, `^`, `<<`, `>>`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `??`

## Violation

```csharp
bool isEmpty = characters != null &&
characters.Length > 0 &&
string.IsNullOrEmpty(defaultCharacter);

return (gameplay && c.gameplay.Enabled) ||
(showcase && c.showcase.Enabled) ||
(dialogue && c.dialogue.Enabled);
```

Wrapped items are not indented one step from the expression start line.

## Fix

```csharp
bool isEmpty = characters != null &&
    characters.Length > 0 &&
    string.IsNullOrEmpty(defaultCharacter);

return (gameplay && c.gameplay.Enabled) ||
    (showcase && c.showcase.Enabled) ||
    (dialogue && c.dialogue.Enabled);
```

Each wrapped item line is now indented one step from the expression start line.

## Notes

- GM0049 complements GM0046 and only evaluates indentation when the operator is already placed at the end of the previous line.
- Single-line expressions are not affected.

## Settings

- `indent_size`: Controls how many spaces one indentation step uses when the base indentation is space-based.
- If `indent_size` is missing or invalid, the default step is 4 spaces.
- If base indentation is tab-based, the expected step is one tab.
