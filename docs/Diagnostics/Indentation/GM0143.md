# GM0143: Each clause in a compound statement must start on its own line

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0143      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

In compound statements (`if`/`else if`/`else` and `try`/`catch`/`finally`), each clause keyword must appear on its own line. A clause keyword must not follow the closing brace `}` of the preceding block on the same line.

Applies to:

- `else` and `else if` clauses following an `if` block
- `catch` clauses following a `try` or previous `catch` block
- `finally` clauses following a `try` or `catch` block

Single-line constructs where the opening and closing braces are on the same line are not checked.

## Violation

```csharp
try
{
    DoSomething();
} catch (Exception e)       // 'catch' on the same line as '}'
{
    HandleError(e);
} finally                   // 'finally' on the same line as '}'
{
    Cleanup();
}

if (condition)
{
    DoA();
} else                      // 'else' on the same line as '}'
{
    DoB();
}
```

## Fix

```csharp
try
{
    DoSomething();
}
catch (Exception e)
{
    HandleError(e);
}
finally
{
    Cleanup();
}

if (condition)
{
    DoA();
}
else
{
    DoB();
}
```
