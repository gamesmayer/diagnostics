# GM0115: Array initializer braces must be indented at the declaration level

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0115      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Opening and closing braces of an array initializer must be indented at the same level as the containing field, property, or local variable declaration.

## Violation

```csharp
class C
{
    int[] arr = new int[]
        {          // GM0115 — over-indented
        0,
        1
        };         // GM0115 — over-indented
}
```

## Fix

```csharp
class C
{
    int[] arr = new int[]
    {
        0,
        1
    };
}
```

## Notes

- The rule applies only to array initializers that are initial values of a declaration (field, local variable, or property). Array creation expressions used as arguments or return values are not checked.
- If the opening brace is on the same line as the declaration, the brace is not checked.
