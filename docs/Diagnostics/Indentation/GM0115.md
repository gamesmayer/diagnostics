# GM0115: Constructor initializer must be indented one step from the declaration

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0115      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Constructor initializer clauses (`base(...)` or `this(...)`) must be indented exactly one step to the right of the constructor declaration.

## Violation

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x) :
base(x)
    {
    }
}
```

The constructor initializer is not indented one step from the declaration.

## Fix

```csharp
class Bar
{
    public Bar(int x) { }
}

class Foo : Bar
{
    public Foo(int x) :
        base(x)
    {
    }
}
```

## Notes

- The rule only applies when the initializer is on a separate line from the constructor declaration.
- When the initializer is on the same line as the declaration, this rule does not trigger (see GM0133).
