# GM0033: Opening parenthesis on a separate line must be indented at declaration level

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0033  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When a non-empty argument or parameter list spans multiple lines and the opening parenthesis is on its own line (Allman style), that line must be indented at the same level as the declaration line.

## Violation

```csharp
public DialogueCharacterState CreateState
  (
    string key,
     CharacterEmotion emotion
)
{
}
```

The opening parenthesis `(` is not indented at the same level as `CreateState` declaration line.

## Fix

```csharp
public DialogueCharacterState CreateState
(
    string key,
     CharacterEmotion emotion
)
{
}
```

## Notes

- The rule applies only to multi-line non-empty argument or parameter lists.
- The rule applies only when `(` is on a separate line from the declaration (Allman style scope).
- A diagnostic is reported only on the opening parenthesis token `(`.
- K&R-style lists (where `(` is on the declaration line) are not checked by this rule.
