# GM0054: 'where' constraint clause must be indented one step from the declaration

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0054  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Each `where` constraint clause must be indented exactly one step to the right of the containing declaration. The indent step is determined by the `indent_size` EditorConfig setting (default: 4 spaces).

## Violation

```csharp
// Not indented
public void Foo<T>()
where T : System.IDisposable { } // GM0054

// Same indentation as declaration
public void Foo<T>()
    where T : System.IDisposable { } // GM0054 (when method is at 4 spaces)

// Over-indented
public void Foo<T>()
            where T : System.IDisposable { } // GM0054
```

## Fix

```csharp
public void Foo<T>()
    where T : System.IDisposable { }

public static void Bar<T, U>(SomeContainer container)
    where T : ISomeInterface
    where U : SomeBase
{
}
```

## Notes

- This rule only applies when the `where` clause is already on its own line. Use GM0053 to enforce that each clause is on its own line.
- The indent step is one unit to the right of the declaration's first token line, regardless of where the closing parenthesis or other tokens appear.
