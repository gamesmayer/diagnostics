# GM0077: Block contents must be indented one step from the block braces

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0077  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

Statements inside a block must be indented by exactly one step relative to the indentation of the line containing the opening brace. This mirrors the behavior of the `csharp_indent_block_contents = true` EditorConfig setting as an enforced diagnostic.

## Violation

```csharp
void Method()
{
int x = 1;
int y = 2;
}
```

## Fix

```csharp
void Method()
{
    int x = 1;
    int y = 2;
}
```
