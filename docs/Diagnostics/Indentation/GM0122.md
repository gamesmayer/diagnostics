# GM0122: Object initializer members must be indented one step from the declaration

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0122      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Members inside the braces of an object initializer must be indented exactly one step to the right of the line containing the `new` keyword.

## Violation

```csharp
var entry = new EditorConfigEntry
{
directory = "",         // GM0122 — under-indented
url = "https://...",    // GM0122 — under-indented
};
```

## Fix

```csharp
var entry = new EditorConfigEntry
{
    directory = "",
    url = "https://...",
};
```

## Notes

- The expected indentation is the `new` keyword line indent plus one `indent_size` step (default 4 spaces).
- Members on the same line as the opening brace are not checked.
