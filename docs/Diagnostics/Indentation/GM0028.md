# GM0028: Closing parenthesis indentation in multi-line argument/parameter list

| Property     | Value   |
| ------------ | ------- |
| **ID**       | GM0028  |
| **Category** | Indentation  |
| **Severity** | Warning |
| **Default**  | Yes     |
| **Fixable**  | Yes     |
| **Settings** | No      |

## Description

When an argument or parameter list spans multiple lines, the closing parenthesis must be indented at the same level as the line containing the opening parenthesis.

## Violation

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
        );
```

The closing parenthesis `)` is over-indented relative to the line where the list starts.

## Fix

```csharp
state = new SkipDialogueLineAnswerState(
    entity: skipEntity,
    dialogueKey: skipEntity.DialogueKey,
    lineIndex: skipEntity.LineIndex,
    index: skipEntity.Index,
    isEnabled: isEnabled
);
```

## Notes

- The rule only applies to multi-line argument/parameter lists.
- A diagnostic is reported only on the closing parenthesis token `)`.
- This rule complements `GM0026`: if `)` is on the same line as the last item, `GM0026` is responsible for reporting that violation.
