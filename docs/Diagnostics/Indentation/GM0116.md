# GM0116: Array initializer items must be indented one step from the declaration

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0116      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Items inside the braces of an array initializer must be indented exactly one step to the right of the containing field, property, or local variable declaration. The indent step is determined by the `indent_size` EditorConfig setting (default: 4 spaces).

## Violation

```csharp
class C
{
    int[] arr = new int[]
    {
    0,      // GM0116 — not indented one step from declaration
    1       // GM0116 — not indented one step from declaration
    };
}
```

## Fix

```csharp
class C
{
    int[] arr = new int[]
    {
        0,
        1
    };
}
```

## Notes

- The rule applies only to array initializers that are initial values of a declaration (field, local variable, or property). Array creation expressions used as arguments or return values are not checked.
- Items on the same line as the opening brace are not checked.
