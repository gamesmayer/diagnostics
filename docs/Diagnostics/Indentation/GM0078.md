# GM0078: Brace must be indented at the declaration level

| Property     | Value       |
| ------------ | ----------- |
| **ID**       | GM0078      |
| **Category** | Indentation |
| **Severity** | Warning     |
| **Default**  | Yes         |
| **Fixable**  | Yes         |
| **Settings** | No          |

## Description

Opening and closing braces must be indented at the same level as the containing declaration. Applies to:

- Blocks (method bodies, `if`, `for`, etc.)
- Class, struct, and namespace declarations
- Array initializers (field, property, and local variable declarations only)
- Object initializers (`new TypeName {}`, `new() {}`, and anonymous object creation)

A brace that is on the same line as the declaration (K&R style) is not checked.

## Violation

```csharp
void Method()
        {           // over-indented
    int x = 1;
        }           // over-indented
```

## Fix

```csharp
void Method()
{
    int x = 1;
}
```
