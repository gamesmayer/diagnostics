# GM1201: Elements must appear in the correct order

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1201   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

An element within a C# code file is out of order in relation to the other elements in the code. The expected order is: fields, constructors, destructors, delegates, events, enums, interfaces, properties, indexers, methods, structs, classes.

## Violation

```csharp
public class Foo
{
    public void Method() { } // GM1201 — method before field

    public int Value;
}
```

## Fix

```csharp
public class Foo
{
    public int Value;

    public void Method() { }
}
```
