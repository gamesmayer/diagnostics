# GM1211: Using alias directives must be ordered alphabetically by alias name

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1211   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

The `using` alias directives within a C# code file are not sorted alphabetically by alias name.

## Violation

```csharp
using Vec3 = UnityEngine.Vector3;
using Color = UnityEngine.Color; // GM1211 — 'Color' should come before 'Vec3'
```

## Fix

```csharp
using Color = UnityEngine.Color;
using Vec3 = UnityEngine.Vector3;
```
