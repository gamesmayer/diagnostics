# GM1207: The keyword `protected` must come before `internal`

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1207   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

In a `protected internal` or `private protected` modifier pair, the keywords must appear in the correct order: `protected` before `internal`, and `private` before `protected`.

## Violation

```csharp
internal protected void Foo() { } // GM1207
```

## Fix

```csharp
protected internal void Foo() { }
```
