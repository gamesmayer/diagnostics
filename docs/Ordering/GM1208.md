# GM1208: System using directives must be placed before other using directives

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1208   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

A `using` directive for a `System` namespace appears after a `using` directive for a non-`System` namespace. System using directives must be placed first.

## Violation

```csharp
using UnityEngine;
using System.Collections; // GM1208
```

## Fix

```csharp
using System.Collections;
using UnityEngine;
```
