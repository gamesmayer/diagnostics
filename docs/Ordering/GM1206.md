# GM1206: Declaration keywords must follow order

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1206   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

The keywords within the declaration of an element do not follow the standard ordering scheme. Keywords must appear in this order: access modifiers first, then `static`, then all other keywords (e.g. `readonly`, `abstract`, `virtual`, `override`, `sealed`, `async`).

## Violation

```csharp
static public int Counter; // GM1206 — 'static' before 'public'
```

## Fix

```csharp
public static int Counter;
```
