# GM1216: Using static directives must be placed at the correct location

| Property     | Value    |
| ------------ | -------- |
| **ID**       | GM1216   |
| **Category** | Ordering |
| **Severity** | Warning  |
| **Fixable**  | No       |

## Description

A `using static` directive is placed before a normal `using` directive or after a `using` alias directive. Using static directives must appear after all normal using directives and before any alias using directives.

## Violation

```csharp
using static System.Math; // GM1216 — before normal usings
using System;
```

## Fix

```csharp
using System;
using static System.Math;
```
